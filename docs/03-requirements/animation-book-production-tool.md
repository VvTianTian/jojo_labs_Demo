- 支持通过拖拽手柄调整图层顺序，以及通过眼睛按钮隐藏或恢复元素。隐藏只影响画布显示，元素仍保留在图层列表中，且不改变出现顺序、播放顺序或音频配置。

- 以 Figma 节点 `12244:83447` 为视觉基准，优化图片和动效画布需求卡的收起、编辑和展示状态。
- 图片/动效置入时保持居中和既有初始尺寸，默认展开“未填写需求”展示态，但不自动进入编辑或聚焦输入框。

- “未填写需求”与已填写需求的展示内容均支持教研人员单击进入编辑态，制作人员端仍保持只读展示。
- 展示态按元素独立保留，点击其他元素或画布空白不自动收起；切换页面或角色时清除临时展开状态，需求内容保留。
- 制作人员可移动、缩放图片/动效并展开或收起需求，但不能编辑需求正文。

### 2026-09-04 · 制作人员图片框直接上传

- 制作人员点击图片框内容区域即可打开图片上传；需求按钮及需求区域继续独立处理展开/收起。
- 制作人员 Hover 图片框时显示上传和删除按钮；上传用于替换图片，删除只清空图片产物，不删除图片框、几何属性或需求内容。
- 图片上传后在图片框内使用等比例完整展示，不拉伸变形；图片框仍支持移动和缩放。
- 制作人员未上传图片时，图片需求默认展开；图片上传成功后需求默认收起，用户仍可通过需求按钮重新展开。

### 2026-09-03 · 文本与领读语音补充需求优化

- 正文页 `TextElement` 默认使用 PingFang 字体、16px、400、normal、24px（150%）的渲染属性；封面文字和对话气泡保持现有字体层级。
- 文本和对话元素新增 `voiceSupplement` 字段，默认值为空，与现有 `audioUrl` 独立保存。
- `领读语音` 页签按当前页面元素写入顺序聚合文本和对话，并按类型独立编号；台词文案只读展示，补充需求可由教研人员维护。
- 无补充需求时显示灰色“补”入口，有需求时使用专业蓝 `#316CE3`；制作人员继续使用原有音频需求槽位上传音频，教研人员不上传音频。

### 2026-09-03 · 文本横向拖动与高度自适应

- 选中文本元素时提供左右中点横向缩放手柄；拖动手柄只调整文本框的横向位置/宽度，保留既有四角缩放能力。
- 横向调整文本框宽度时，文本按新的可用宽度换行，并根据实际内容自动更新高度；文本框不显示滚动条。
- 上述尺寸交互只改变文本元素几何属性，不改变文本内容、标注、字体样式、`voiceSupplement`、`audioUrl` 或其他页面顺序数据。

### 2026-09-03 · 正文文本默认首行缩进

- 正文页文本默认设置 `Paragraph indent = 32px`，对应 16px 正文下首行空两格；该默认样式不改变封面文字和对话气泡。
- 首行缩进属于正文文本的渲染默认值，用户主动编辑文本内容或显式格式时仍保留该默认段落缩进。

### 2026-09-04 · 文本编辑占位、段落换行与光标稳定

- 正文文本内容为空时，画布默认显示占位文案“**双击编辑文字**”；占位文案仅用于界面提示，不写入 `TextElement.content`，也不进入“领读语音”台词文案。
- 文本编辑器使用真实换行保存段落边界；用户按 `Enter` 创建新段落后，新段落首行同样使用 `text-indent: 32px` 的视觉缩进。
- 自动折行只由文本框宽度和排版决定，不为每个视觉折行额外插入空格；`content` 中不写入用于排版的模拟空格，避免“领读语音”文案出现多余字符。
- 文本输入、中文输入法组合输入、粘贴多行文案和替换选中文本时，光标应保持在用户实际输入位置，不因 React 重渲染跳回文本开头。
- 文本框继续不显示滚动条；横向拖动后的高度自适应、正文默认样式、标注字符范围和语音配置均不因编辑器内部同步方式改变。

### 2026-09-03 · 题元素与题 Tab MVP

- 正文页每页最多添加一个 `QuestionElement`；封面不提供题入口，也不显示题相关页码信息。
- 题是页面静态元素，使用 `stem`、`optionMode` 和 `options` 保存题干、选项模式和选项内容；选项支持 2–4 项，默认创建 A-D 四个空文本选项，支持多选正确答案。
- 题固定在画布右上区域，目标画布坐标为 `x=1044`、`y=198`、`width=540`、`height=612`（640×360 编辑画布按比例缩放）；不可拖动、缩放或进入播放顺序。
- 画布右下角显示正文页码 `当前页/正文总数`；当前页存在题时追加“题”徽标，题被图层隐藏后徽标仍保留。封面和没有题的正文页不显示对应信息。
- 工具栏中的 `题` 在正文页可新增或打开当前题并自动切换题 Tab；`互动` 初始可点击但仅提示“下一版本开放”，添加题后置灰；封面两个入口均不可用。
- 题可在图层中选择、隐藏和恢复；选中题后按 `Delete` / `Backspace` 始终弹出二次确认，取消、`ESC` 或点击遮罩均不删除，确认后同步移除页面元素和图层顺序。
- 题 Tab 仅将题干文字、文本选项、选项数量和正确答案设置作为本期功能；图片选项、材料、答案、解析、标签及语音入口保留 Figma 视觉占位。制作人员可以查看题 Tab 和题内容，但不能修改。
- 题为空时画布显示“暂无内容”；本期只维护前端本地状态，不接入接口、数据库、持久化、C 端答题反馈或跳转逻辑。

## 需求背景

现有绘本编辑器偏向结构化内容录入，文本、图片和语音主要以表单或内容块的形式组织。动画书需要更接近 PPT 的自由编排方式：教研人员可以在固定画布中组合文本、图片、对话气泡和动效占位，并通过图层、出现顺序和播放顺序控制最终动画书的呈现逻辑；制作人员根据教研需求补齐图片、动效和音频产物。

最终内容会在 C 端以 1920×1080 的横屏动画书形式展示。B 端生产工具不直接承担统一预览、发布或审校职责，但数据结构和页面布局需要为后续互动内容、动画、双语和审校流程留出扩展空间。

参考资料包括：

- C 端动画书效果截图：用于理解封面、正文、图片、文本高亮示例和对话气泡等内容形态。
- 「翻翻书生产工具」的编辑态与审校态截图：用于确定审校区的动态布局方式。
- Figma 节点 `11687-197037`：用于后续实现阶段的视觉与几何对齐，本需求文档优先定义业务范围。

## 目标用户

- **主要用户**：公司内部教研人员和制作人员。
- **使用前提**：用户已经拥有或准备好动画书中的图片、文本和音频素材。
- **间接用户**：C 端儿童及家长，消费生产完成后的动画书内容；不直接使用本工具。
- **未来协作用户**：审校人员。本期不实现审校功能，仅定义未来状态切换时的布局约束。

## 业务目标

1. 让教研人员在固定的 16:9 画布中完成动画书页面编排。
2. 让文本、图片、语音和气泡等内容成为可独立选择、移动和排序的页面元素。
3. 支持音频播放顺序与页面元素出现顺序的独立配置。
4. 支持文本、图片、气泡重叠场景下的图层顺序调整。
5. 通过可扩展的元素模型，为互动答题、动画资源、双语和审校流程保留后续接入空间。
6. 让教研需求与制作产物在同一本动画书内建立明确绑定，降低交接成本。

- 作为教研人员，我希望为每个文本块和对话气泡配置一条语音需求，以便制作人员产出可单独播放的语音。

- 作为教研人员，我希望调整元素图层、出现顺序和音频播放顺序，以便控制页面的视觉和听觉节奏。

## 产品范围

### MVP 包含

- 生产工作区及页面缩略图列表。
- 封面编辑：左右布局、全屏布局；封面固定在页面列表顶部且不参与正文排序。
- 正文页面新增、复制、删除和拖拽排序。
- 固定 1920×1080 目标画布，B 端编辑视图使用等比例 640×360 画布。
- 文本元素、图片元素、动效占位和对话气泡元素的新增和编辑。
- 正文页静态题元素与题 Tab MVP：每页最多一个题，支持题干、2–4 个文本选项和多选正确答案编辑。
- 文本块语音需求和对话气泡语音需求的配置；`领读语音` 页签聚合两类语音源。
- 文本标注：好词、好句、注释；支持多条标注、范围重叠、对应样式和配置面板。
- 标注中的“语音-需求/补充”仅保存制作需求文案；不创建音频源，不由制作人员通过音频需求槽位上传，也不进入播放顺序。
- 页面元素的上移、下移、置顶、置底。
- 画布内悬浮图层顺序工具；支持图层拖拽排序、键盘顺序调整和元素隐藏/恢复。
- 页面元素出现顺序和音频播放顺序的配置入口。
- 互动内容仍保留下一阶段入口；本轮不创建互动业务数据或实现 C 端互动。
- 图片、动效和音频需求槽位；需求支持轻量富文本、图片和图片说明。
- 制作人员产物上传、产物状态展示和有限几何微调。
- 基础上传失败、空状态和内容不完整提示。
- 选中文字后的浮动文本工具栏，以及 `+好词`、`+好句`、`+注释` 三个创建入口。

### MVP 不包含

- C 端播放态或统一预览入口。
- 导出、发布和与现有系统的数据联调。
- 审校区及审校批注、筛选、状态处理等功能。
- 固定预留审校区宽度。生产态的编辑展示区保持居中。
- TTS 自动生成语音；文本和气泡语音均由制作人员通过需求槽位上传。
- 标注对应音频的自动生成、录音、上传、播放和播放顺序配置；标注语音字段本期仅为需求文案。
- 页面级独立 `leadReading` 需求、领读字幕和领读语音时间轴；本期 `领读语音` 仅聚合文本/对话语音，题不产生音频源。
- 动效预设、动效时间轴和动效播放实现；本期动效仅静态占位或文件卡片展示。
- 元素锁定和组合；图层隐藏/恢复属于本轮 MVP 能力。
- 互动答题等点击交互的具体实现；静态题元素的题干、文本选项和正确答案配置除外。
- 中英文双语同屏或逐段翻译。

## 工作区与布局

### 生产态（MVP）

生产态不占用、不预留最右侧审校区域。整体结构为：

```text
顶部工具栏
┌──────────────┬──────────────────────────────────────┐
│ 页面缩略图区 │ 中央编辑工作区                         │
│              │ 640×360 画布 + 元素编辑/配置            │
└──────────────┴──────────────────────────────────────┘
```

- 页面缩略图区负责封面入口、正文页面选择、页面排序和页面状态提示。
- 中央编辑工作区负责画布展示、元素选择、元素编辑和顺序配置。
- 编辑画布工具与网格系统位于中央编辑工作区顶部的吸顶工具栏，工具栏随编辑区滚动保持在顶部。
- 画布在当前可用编辑区域内水平居中，不因为未来审校功能而提前左移。
- 元素属性和顺序设置属于生产编辑能力，可以在中央工作区内通过属性面板、底部面板或上下文面板承载；具体视觉位置以后续 Figma 设计为准。
- 生产态不出现审校批注、审校筛选或审校状态控件。

### 审校态（后续扩展）

审校态不作为 MVP 页面实现，但必须保留以下布局约束：

- 进入审校态后，动态增加最右侧审校区。
- 动画书工作区自动向左移动，以适配审校区。
- 生产态不因为该能力预留固定空白区域。
- 审校区的宽度、批注结构、筛选和状态流转另行设计。

## 页面清单

| 页面/区域 | 入口 | MVP 范围 |
| --- | --- | --- |
| 动画书生产工具 | Demo 首页或工具入口 | 新增生产工作区 |
| 封面编辑 | 左侧页面列表中的“封面” | 支持左右布局、全屏布局，不参与排序 |
| 正文页面编辑 | 左侧正文缩略图 | 支持元素编辑、图层和顺序配置 |
| 页面缩略图区 | 生产工作区左侧 | 支持选择、排序、新增、复制、删除 |
| 审校区 | 后续审校态 | MVP 不实现，不预留固定区域 |

## 页面与元素模型

### 书籍级字段

| 字段 | 类型 | 必填 | 规则 |
| --- | --- | --- | --- |
| `bookId` | 字符串 | 是 | 当前动画书唯一标识 |
| `title` | 字符串 | 是 | 动画书名称 |
| `language` | `zh` / `en` | 是 | 一本书当前只支持一种语言；不支持中英文同时维护 |
| `canvasWidth` | 数字 | 是 | 固定为 1920 |
| `canvasHeight` | 数字 | 是 | 固定为 1080 |
| `editorWidth` | 数字 | 是 | B 端编辑视图采用 640 |
| `editorHeight` | 数字 | 是 | B 端编辑视图采用 360 |
| `cover` | 封面对象 | 是 | 单独保存，不进入正文页面排序 |
| `pages` | 页面数组 | 是 | 仅正文页面参与排序 |

### 封面字段

| 字段 | 类型 | 必填 | 规则 |
| --- | --- | --- | --- |
| `coverLayout` | `split` / `fullscreen` | 是 | 左右布局 / 全屏布局；仅教研端可写入，制作端只读 |
| `elements` | 元素数组 | 是 | 封面固定模板元素；文字只允许修改内容，不能修改几何、字号、字体或样式 |

封面固定展示在缩略图列表顶部，不能通过拖拽与正文页面交换位置，也不能被删除为普通正文页。

### 页面字段

| 字段 | 类型 | 必填 | 规则 |
| --- | --- | --- | --- |
| `pageId` | 字符串 | 是 | 页面唯一标识 |
| `order` | 数字 | 是 | 仅用于正文页面排序 |
| `elements` | 元素数组 | 是 | 页面内所有可视元素 |
| `appearanceOrder` | 元素 ID 数组 | 是 | 页面元素的出现顺序；不使用时间轴 |
| `playbackOrder` | 播放顺序项数组 | 是 | 当前正文页文本、图片、动效和对话元素的播放顺序及展示方式；题不进入 |
| `animation` | 动效对象 | 否 | 每页最多一个；MVP 仅预留结构，不实现播放 |
| `interaction` | 扩展对象 | 否 | 为互动答题等点击交互预留，MVP 不实现 |

### 通用元素字段

所有可视元素至少包含：

| 字段 | 类型 | 规则 |
| --- | --- | --- |
| `elementId` | 字符串 | 元素唯一标识 |
| `type` | 枚举 | `text`、`image`、`motion`、`bubble`、`question`；未来扩展 `interaction` |
| `x` / `y` | 数字 | 在 1920×1080 目标画布中的位置 |
| `width` / `height` | 数字 | 在目标画布中的尺寸 |
| `zIndex` | 数字 | 页面内图层顺序 |
| `hidden` | 布尔值，可选 | `true` 时不在画布渲染，但仍保留在图层列表；缺省视为 `false` |

当前不提供 `locked` 和 `groupId` 的编辑能力；`hidden` 仅由教研人员通过图层顺序工具编辑。

### 题元素字段

| 字段 | 类型 | 必填 | 规则 |
| --- | --- | --- | --- |
| `stem` | 字符串 | 是 | 题干文字；默认空字符串，空内容在画布显示“暂无内容” |
| `optionMode` | `text` / `image` | 是 | 默认 `text`；图片选项本期只展示不可用占位 |
| `options` | 题目选项数组 | 是 | 2–4 项；默认四项 A-D，选项内容默认为空 |
| `options[].id` | 字符串 | 是 | 当前题内选项唯一标识 |
| `options[].content` | 字符串 | 是 | 文本选项内容；本期支持编辑 |
| `options[].isCorrect` | 布尔值 | 是 | 是否为正确答案；允许同时选择多个 |

题元素继承通用元素的 `hidden`、`zIndex` 和图层操作模型，但位置和尺寸固定为 `x=1044`、`y=198`、`width=540`、`height=612`。题不进入页面 `playbackOrder`，也不参与音频播放。

### 播放顺序项

播放顺序项只存在于正文页的 `playbackOrder` 中，按页面元素顺序保存。每项包含元素 ID 和该元素的展示方式；本期只编辑并保存配置，不接入 C 端播放引擎或统一预览。

| 字段 | 类型 | 规则 |
| --- | --- | --- |
| `elementId` | 字符串 | 必须指向当前页面存在的元素 |
| `displayMode` | `always` / `onPlayback` | 默认 `always`，对应“一直出现”；`onPlayback` 对应“播放时出现” |

### 文本元素

- 每个文本元素可编辑文本内容。
- 文本元素可以在画布中移动和调整尺寸。
- 文本元素支持左右中点横向拖动调整宽度；横向拖动后高度根据换行内容自动适配，文本框不显示滚动条。
- 正文页文本默认使用 PingFang 字体，`font-size: 16px`、`font-style: normal`、`font-weight: 400`、`line-height: 150%`（24px），并设置首行 `text-indent: 32px`；封面文字不套用该默认值。
- 文本浮动工具栏保留显式的加粗、斜体、下划线、颜色和对齐操作；用户主动操作后允许形成对应的显式样式变化。
- 一个文本块绑定一条文本语音。
- 文本语音必须由制作人员通过对应需求槽位上传；MVP 不提供 TTS 自动生成。
- 文本元素包含 `voiceSupplement` 字符串，默认为空，用于记录语气、音色、语速等台词内容之外的领读语音补充要求；该字段不替代 `audioUrl`。
- 文本可以创建多个好词、好句或注释标注；标注只记录字符范围和学习配置，不改变文本元素尺寸、网格或排版。
- 文本不增加双语翻译字段；整本书通过 `language` 表示中文或英文之一。

### 文本标注

文本标注挂载在文本元素上，字符范围使用文本内容的 UTF-16 字符索引 `start` / `end`，采用左闭右开区间。标注原文由范围自动派生保存，文本内容变化后仅保留仍在合法范围内的标注。

| 字段 | 类型 | 规则 |
| --- | --- | --- |
| `annotationId` | 字符串 | 标注唯一标识 |
| `type` | `word` / `sentence` / `note` | 好词 / 好句 / 注释 |
| `start` / `end` | 数字 | 选中文字范围；允许不同标注重叠 |
| `text` | 字符串 | 当前范围对应的原文 |
| `pronunciationMode` | `pinyin` / `phonetic` | 仅好词使用 |
| `pinyin` | 字符串 | 好词拼音 |
| `translations` | 字符串数组 | 好词或好句翻译，可多行 |
| `explanation` | 字符串 | 好词或好句扩展讲解 |
| `note` | 字符串 | 注释内容 |
| `voiceRequest` / `voiceSupplement` | 字符串 | 语音制作需求文案，不是音频源 |

标注展示规则：

- 好词使用橙色高亮。
- 好句使用波浪下划线。
- 注释使用虚线下划线。
- 多条标注同时作用于同一字符范围时样式叠加；任何标注操作都不得改变文本块的几何尺寸、网格或排版。
- 单击已有的好词、好句或注释标注块时，底部自动切换到对应标注页签并激活该标注编辑项；重叠标注按创建顺序打开最早创建的一条，不进入文本编辑态或修改原文。
- 鼠标悬停标注时显示删除按钮；有配置内容时删除必须二次确认，无配置内容时直接删除，删除不影响原文。

### 图片元素

- 页面允许存在多个图片元素。
- 图片元素可独立选择、移动、调整尺寸，并参与图层排序。
- 图片素材由制作人员通过对应需求槽位上传或替换，MVP 使用本地上传演示。
- 图片可以与文本、气泡重叠，重叠时按照图层顺序渲染。

### 语音与领读语音页签

- `领读语音` 是编辑区下方的聚合页签，不代表新的页面级音频模型。
- 页签只展示当前页面的文本和对话元素；按 `page.elements` 写入顺序排列，类型编号独立递增，例如“文本1、对话1、文本2”。
- 每项的台词文案只读展示，并提供“补”字入口维护 `voiceSupplement`。无补充需求时入口为灰色，Tooltip 为“暂无音频补充要求（如语气、音色等台词内容以外的要求）”；有补充需求时入口使用专业蓝 `#316CE3`，Tooltip 展示补充内容。
- 台词文案承载区使用 `#D0DFE7`、10% 透明度（`rgba(208, 223, 231, 0.1)`）；领读语音列表项外层不额外设置背景色。
- 点击“补”打开“领读语音需求”弹窗：台词需求自动取当前文本/对话文案且不可编辑，补充需求支持多行纯文本编辑；确认保存，取消、关闭、ESC 或遮罩关闭均不保存，保存空内容恢复为空状态。
- 文本/对话元素的 `voiceSupplement` 与 `audioUrl` 独立维护；教研人员只维护补充需求，制作人员继续通过既有音频需求槽位上传或替换音频。
- 文本标注中的 `voiceRequest` / `voiceSupplement` 仍是标注制作需求文案，不生成音频源，不在页签中单独列出，也不参与 `playbackOrder`。
- `播放顺序`是当前正文页文本、图片、动效和对话元素的顺序编辑入口；题为静态元素，不进入播放顺序；每项可独立设置“一直出现”或“播放时出现”。
- `播放顺序`在内容面板右侧以独立 Tab 按钮呈现，与动态页签保持相同激活和切换语义，但视觉上与`领读语音`、标注页签分开。

### 对话气泡

- 页面可以添加多个对话气泡。
- 气泡宽度和高度可以直接拖拽调整。
- 气泡中的文字根据气泡当前尺寸自动换行。
- 气泡三角可以沿气泡边缘拖拽，指向画面中发出对话的对象或位置。
- 气泡支持方向设置；不包含角色名和头像。
- 气泡可绑定一条制作人员上传的语音，并参与页面音频播放顺序。
- 气泡包含 `voiceSupplement` 字符串，默认为空，用于记录领读语音补充要求；对话气泡的既有字体层级和 `audioUrl` 上传模型保持不变。
- 为后续目标元素关联预留 `targetElementId`，MVP 可以先保存为空或仅保存三角落点。

### 动效资源（扩展预留）

- 动效被定义为一个会动的图片资源，不是整页转场效果。
- 每页最多支持一个动效资源。
- 后续可配置“一直动”或“只动一次”。
- 后续可配置动效触发方式。
- MVP 不实现动效预设、时间轴、播放或触发配置；制作人员可以上传动效文件，画布以静态占位或文件卡片展示，数据结构不将动效错误建模为普通图片。

### 产物需求槽位

- 每个封面或正文页面可以配置多个产物需求槽位，类型为 `image`、`motion` 或 `audio`。
- 每个槽位包含标题、轻量富文本需求、内嵌参考图片、目标对象和一个制作产物。
- 图片/动效槽位可以绑定图片或动效元素；音频槽位可以绑定文本或气泡。
- 槽位状态为 `pending`、`uploaded` 或 `failed`，上传失败不覆盖原有产物。
- 图片槽位绑定图片元素时，制作人员也可以从画布图片框直接上传或替换图片；上传后的图片保持比例并完整显示在图片框内。
- 画布图片框上的删除操作只清空图片产物，保留图片元素的尺寸、位置、需求和绑定关系。
- 教研人员可编辑需求和绑定关系；制作人员只能查看需求、上传/替换产物并进行允许的几何微调。

#### 图/动效画布需求卡

- 每个已绑定需求的图片或动效元素都显示“需求”按钮，并支持收起、编辑和展示三种临时 UI 状态。
- 图片/动效元素新增时保持现有居中位置和固定初始宽高；需求卡默认展开为展示态，空内容显示“未填写需求”，但不得自动聚焦输入框。
- 教研人员在收起态点击“需求”按钮进入展示态；展示态单击需求内容区进入富文本编辑态并自动聚焦，编辑态失焦后转为展示态，展示内容常驻直到再次点击该元素的“需求”按钮。
- 已填写和空内容的展示区均可作为教研编辑入口；制作人员端该内容区不可编辑。
- 需求按钮固定在图片/动效框架左下角；展开后的需求内容面位于按钮右侧，并保持在当前框架内。
- 需求内容面随图片/动效框架尺寸变化同步伸缩，优先保持当前默认宽度；空间不足时收缩到可用最小宽度，不主动溢出框架。
- 教研人员在编辑态再次点击“需求”按钮时立即收起，已输入内容保留；展示态和收起态切换不修改需求数据。
- 当前页面内可以同时保留多个元素的展示态；切换页面或角色时关闭临时状态，不丢失已编辑内容。
- 制作人员可以展开或收起需求、移动和缩放图片/动效，但不能编辑需求正文。

### 题元素与互动能力

#### 题元素（本轮 MVP）

- 题作为正文页元素存在，每页最多一个；封面不支持添加题。
- 题使用固定画布几何，不支持拖动、缩放或文本框内编辑；题干和选项只在题 Tab 中编辑并实时回显到画布。
- 默认创建 A-D 四个空文本选项；选项数量可在 2–4 项之间调整，正确答案支持多选，默认没有正确答案。
- 题为空时，题干和每个选项在画布显示“暂无内容”；题卡采用 Figma 的暖黄色背景、棕色描边、圆角和阴影。
- 题保留页面图层和出现模型，但不进入 `playbackOrder`，不产生音频或参与播放执行，也不实现 C 端答题、反馈、跳转和结果。

#### 互动（下一阶段）

- 工具栏中的 `互动` 初始保持可点击，点击仅提示“下一版本开放”；当前页添加题后，`互动` 入口置灰。
- 互动不创建业务数据；后续新增互动类型时，不应破坏现有页面元素、图层和顺序模型。

## 图层与顺序规则

### 图层顺序

- 文本、图片、动效、对话气泡和题均属于页面图层；互动仍为下一阶段扩展。
- 图层顺序工具悬浮在当前画布左下方，默认收起；教研人员点击图层按钮后展开列表，再次点击可收起。
- 列表按 `zIndex` 从高到低展示，第一项代表最上层；拖拽手柄调整顺序后，按元素 ID 更新对应 `zIndex`。
- 当前支持拖拽排序，以及通过键盘方向键、Home、End 完成上移、下移、置顶和置底。
- 每行提供显示/隐藏按钮；隐藏元素从画布消失但保留在图层列表中，恢复后回到原有图层位置。
- 隐藏状态只影响画布渲染，不改变 `appearanceOrder`、`playbackOrder`、展示方式或音频配置。
- 图层调整只影响当前页面，不改变其他页面。
- 封面和正文页面各自维护独立的元素图层。
- 本期不考虑锁定和组合；题支持选择、隐藏/恢复和删除确认，互动只保留图标/名称和入口状态。

### 出现顺序

- 每页维护独立的 `appearanceOrder`。
- 出现顺序用于表达页面元素的先后出现关系。
- MVP 只提供顺序调整，不提供时间轴、时长、缓动或动画预设配置。
- 默认顺序可以根据元素创建顺序生成；用户调整后以显式顺序为准。

### 播放顺序

- 每页维护独立的 `playbackOrder`。
- 播放顺序覆盖当前正文页的文本、图片、动效和对话元素；题是静态画布元素，不进入播放顺序；封面继续不参与本入口的播放顺序配置。
- 列表支持拖拽排序，每个元素独立保存 `displayMode`：`always`（一直出现）或 `onPlayback`（播放时出现）。
- 播放顺序按钮激活时只替换内容面板区域；点击其他动态页签后返回对应内容，不显示旧的“出现顺序 + 播放顺序”双栏面板。
- 本期只保存编辑配置，不实现 C 端播放、预览、时间轴切分或多轨混音。

## 主流程

1. 用户进入动画书生产工具，打开默认动画书或 Demo 初始数据。
2. 系统展示生产态工作区：左侧缩略图列表，中间居中的编辑画布。
3. 用户点击封面，选择左右布局或全屏布局，并编辑封面内容。
4. 用户新增、复制、删除或拖拽排序正文页面；封面始终不参与排序。
5. 用户选择正文页面，在 640×360 画布中添加或编辑文本、图片和对话气泡。
6. 教研人员置入图片或动效后，需求卡默认展示“未填写需求”，但不自动进入编辑；点击收起态的“需求”按钮先展开展示态。
7. 教研人员单击展示态的需求内容进入编辑态并自动聚焦；输入需求并失焦后转为常驻展示态，再次点击“需求”按钮收起需求。
8. 教研人员选中文字，使用浮动工具栏创建好词、好句或注释，并在下方对应页签配置内容。
9. 教研人员在 `领读语音` 页签查看文本和对话语音，制作人员通过既有需求槽位上传对应音频。
10. 用户调整元素位置、尺寸、图层顺序和元素显示状态。
11. 用户在动态页签中打开`播放顺序`，拖拽调整当前正文页文本、图片、动效和对话元素的顺序，并逐项设置展示方式；题不出现在列表中。
12. 系统持续更新当前 Demo 的本地编辑状态，并对明显缺失或不合法内容提供提示。
13. 用户完成本轮编辑后退出工具；预览、发布和审校流程由统一平台后续承接。
14. 教研人员在顶部切换到制作人员，制作人员看到同一页面和同一份需求状态。
15. 制作人员展开或收起需求、上传对应图片/动效/音频，并对图片、动效和气泡进行有限几何调整。
16. 用户切回教研人员，系统保留需求、产物、音频和几何调整结果。

## 异常流程与边界条件

- **图片上传失败**：保留原有图片，显示失败提示，其他页面编辑继续可用。
- **音频上传失败**：不覆盖原有音频，显示失败提示，用户可以重新上传。
- **文件类型不支持**：阻止写入当前元素，并提示允许的文件类型。
- **页面为空**：允许继续编辑，但缩略图显示内容缺失提示。
- **正文页面排序**：只允许正文页面之间排序；拖拽封面时不产生排序变化。
- **删除当前页面**：删除后自动选中相邻正文页面；当页面数量达到最小限制时阻止删除并提示“至少保留一个正文页面”。
- **删除当前元素**：从当前页面移除元素，并将选中状态清空或转移到相邻元素。
- **删除标注**：标注没有配置内容时直接删除；已填写拼音、翻译、讲解、注释或语音需求时弹出确认，取消后保留标注和原文。
- **标注范围重叠**：允许多条标注覆盖同一段文字，按类型叠加展示样式，不改变文本布局。
- **快捷填入**：点击标注面板的“快捷填入”时，将当前标注原文写入“语音-需求”，不创建或修改音频源。
- **新增第二个动效**：MVP 每页允许一个动效占位；再次新增时阻止操作并提示“每页最多一个动效”。
- **新增第二个题**：当前页已有题时再次点击“题”只重新选中并打开题 Tab，不创建第二个题；“互动”入口置灰。
- **题选项数量**：选项数量只能保持在 2–4 项；达到上限时禁用新增，达到下限时禁用删除。
- **题删除确认**：无论题干和选项是否为空，删除题都需要二次确认；取消、`ESC` 和遮罩关闭均保留题。
- **题隐藏**：题隐藏后不渲染题卡，但图层行和页码题徽标保留；恢复后题卡回到固定位置。
- **画布需求为空**：图片/动效需求没有正文时仍默认展示“未填写需求”；不自动进入编辑，教研人员点击收起态的“需求”按钮先展开，再点击展示内容区编辑。
- **需求状态切换**：选中其他元素或点击画布空白不关闭当前页面已展示的需求；切换页面或角色后关闭临时展示状态，需求正文保留。
- **气泡文本过长**：按照气泡尺寸自动换行；不因为文本变长自动改变用户已经设置的气泡尺寸。
- **气泡三角拖拽**：三角落点必须保持在气泡边缘可用范围内；目标对象关联暂不强制校验。
- **缩略图资源加载失败**：显示占位图和失败状态，不阻断页面选择与排序。
- **画布尺寸改变**：MVP 不支持修改画布比例，所有元素坐标以 1920×1080 目标画布保存。
- **角色权限**：制作人员不能通过页面控件、键盘或残留事件修改文字、页面结构、图层和顺序。
- **视觉产物未绑定**：允许产物保存在需求槽位中，但提示“待教研绑定画布位置”。

## 权限规则

本期仍是前端纯编辑 Demo，不新增接口、数据库或真实登录鉴权；角色仅用于演示不同工作视图。

- 教研人员：创建和编辑文字、页面结构、元素布局及产物需求；不可上传制作产物。
- 教研人员：创建和编辑题元素、题干、文本选项和正确答案；题的位置和尺寸固定。

- 审校人员、管理或发布角色：仍属于后续扩展范围。

## 验收标准

### 工作区与页面管理

1. 生产态不显示、也不预留固定审校区，中央编辑画布在可用区域内居中。
2. 左侧展示封面和正文页面缩略图，封面固定在列表顶部。
3. 封面支持左右布局和全屏布局。
4. 封面不能通过拖拽与正文页面交换顺序。
5. 正文页面支持新增、复制、删除和拖拽排序。
6. 选中缩略图后，中间画布切换到对应封面或正文页面。
6a. 点击“添加页面”后，新正文页默认不创建文本或其他元素，画布和缩略图显示空白状态；用户通过“文字”入口主动添加文本。

### 画布与元素

7. 编辑画布按照 1920×1080 的比例展示，编辑视图基准尺寸为 640×360。
8. 页面至少支持文本、图片、动效占位和对话气泡四类可编辑元素。
9. 元素可以在画布中被选中，并显示当前元素的编辑边界或明确选中状态。
10. 文本、图片和气泡可以发生重叠，渲染结果遵循当前页面图层顺序。
11. 页面可以存在多个图片和多个对话气泡。
11a. 文本元素支持左右中点横向拖动调整宽度；拖动时按换行内容自动适配高度，文本框不显示滚动条。
11b. 正文文本默认首行缩进 `32px`，即 16px 正文的两个字符宽度；封面文字和对话气泡不受影响。
11c. 正文文本为空时画布显示“**双击编辑文字**”，占位文案不计入文本内容和领读语音台词。
11d. 用户按 `Enter` 产生的新段落首行同样缩进 `32px`；自动折行不向文本内容写入额外空格。
11e. 文本输入、中文输入法组合输入、粘贴和替换选中文本时，光标位置稳定，连续输入顺序与用户操作一致。
12. 气泡宽高可以拖拽调整，文本会根据当前气泡尺寸自动换行。
13. 气泡三角可以沿气泡边缘拖拽并改变指向位置。
14. 气泡支持方向设置，不显示角色名和头像配置。

### 题元素与题 Tab

15. 正文页工具栏可以添加题；封面没有题入口，每个正文页最多存在一个题元素。
16. 添加题后自动选中题并打开“题”Tab；题固定在画布右上区域，选中时只显示选中边框，不显示移动或缩放手柄。
17. 题 Tab 显示计数 `1`，题干文字和文本选项编辑后实时回显到画布；画布题卡本身不可直接编辑文本。
18. 题默认有 A-D 四个空文本选项；选项数量可增删但始终限制在 2–4 项，至少保留两个选项。
19. 每个选项都可以切换正确答案状态，且允许同时选择多个正确答案；默认没有正确答案。
20. 图片选项、材料、答案、解析、标签和语音区域保留 Figma 视觉占位，不产生本轮业务数据。
21. 题可通过图层选择、隐藏和恢复；隐藏题时画布题卡消失，但图层中的题和画布右下角“题”徽标仍保留。
22. 当前正文页页码显示为 `当前页/正文总数`；有题时显示题徽标，封面和无题正文页不显示题徽标。
23. 题选中后按 `Delete` 或 `Backspace` 始终需要二次确认；取消、按 `ESC` 或点击遮罩不删除，确认后移除题元素和图层顺序。
24. 当前页添加题后“互动”入口置灰；无题正文页互动入口可点击但提示“下一版本开放”，不创建互动数据。
25. 切换到制作人员后题干、选项和正确答案保留，题 Tab 可查看但不能修改；切回教研人员后恢复编辑能力。

### 图/动效需求卡

- 图片/动效置入后保持现有居中位置和固定初始宽高，且不自动聚焦需求输入框。
- 已有或新建的空图片/动效需求默认展示“未填写需求”，但不进入编辑态。
- 教研人员点击收起态“需求”按钮后进入展示态；单击展示态的需求内容进入富文本编辑态并获得焦点，输入框失焦后转为展示态并保持展开。
- 已填写和“未填写需求”展示内容均可点击进入编辑；制作人员端点击该内容不进入编辑。
- 需求按钮固定在图片/动效框架左下角，展示/编辑内容面位于按钮右侧且默认不超出框架；框架尺寸变化时内容面同步伸缩。
- 展示态下点击其他元素或画布空白，已展示需求不收起；点击自身“需求”按钮后收起。
- 教研人员编辑态点击自身“需求”按钮立即收起，已输入内容保留；再次打开时内容仍存在。
- 同一页面可同时保留多个需求展示态；切换页面或角色后关闭临时展开状态，需求正文不丢失。
- 制作人员可以展开/收起需求并移动、缩放图片和动效，但不能编辑需求正文或看到富文本工具栏。
- 制作人员未上传图片时图片需求默认展开；图片上传成功后图片需求默认收起，点击“需求”按钮仍可切换状态。
- 制作人员点击图片框内容区域可直接打开图片上传；Hover 图片框显示上传和删除按钮，删除只清空图片产物。

### 音频与标注

15. 每个文本块最多绑定一条由制作人员上传的文本语音；教研人员不在领读语音页签上传音频。
16. 每个气泡最多绑定一条由制作人员上传的气泡语音；既有音频上传/替换流程不因补充需求编辑改变。
17. `领读语音` 页签聚合当前页面的文本和对话元素，不显示页面级独立领读语音；列表按 `page.elements` 写入顺序排列，序号按文本/对话类型独立递增，例如“文本1、对话1、文本2”。
17a. `领读语音` 列表中的台词文案只读展示；每项提供“补”入口。无 `voiceSupplement` 时入口为灰色并提示“暂无音频补充要求（如语气、音色等台词内容以外的要求）”，有内容时入口为 `#316CE3` 并回显补充需求。
17b. 教研人员点击“补”后可在“领读语音需求”弹窗中编辑多行补充需求；台词需求自动取当前文本/对话文案且不可编辑。确认保存，取消、关闭按钮、ESC 或遮罩关闭均不保存；保存空内容会恢复暂无补充需求状态。
18. 选中文字后显示 `+好词`、`+好句`、`+注释`；点击后创建对应标注并切换到对应配置页签。
19. 好词、好句、注释支持多条共存和范围重叠，分别展示橙色高亮、波浪下划线、虚线下划线，且不改变文本布局；单击已有标注块时打开对应编辑项，重叠时按创建顺序打开最早创建的一条。
20. 三类标注字段可编辑；好词支持注音模式、拼音、翻译和扩展讲解，好句支持翻译和扩展讲解，注释支持注释内容；三类均支持语音需求/补充文案。
21. “快捷填入”将当前标注原文写入“语音-需求”；标注语音字段不生成音频源、不显示为独立语音项、不进入播放顺序。
22. 标注悬停显示删除按钮；有配置内容时需要确认，取消确认不删除，无配置内容时可直接删除且原文保留。
23. `播放顺序`作为内容面板右侧的独立 Tab 按钮展示；打开后保留动态页签栏和按钮，仅替换内容区。
24. 播放顺序列表展示当前正文页的文本、图片、动效和对话元素，支持拖拽排序。
25. 每个播放顺序项默认展示方式为“一直出现”，可独立切换为“播放时出现”并保持配置。
26. 点击`领读语音`、`好词`、`好句`或`注释`后，播放顺序内容区关闭并返回对应页签内容；播放顺序按钮保持独立位置。
27. MVP 不显示 TTS 生成入口、标注音频制作入口、字幕时间轴和多领读角色设置。

### 图层与顺序

28. 当前页面的图层顺序通过画布左下角悬浮工具编辑；支持拖拽排序和键盘上移、下移、置顶、置底，底部不显示`页面内容`和`图层顺序`页签。
29. 图层列表展示当前页面全部元素；题支持选择、隐藏/恢复和删除确认，互动仅做兼容识别并保留下一阶段入口。
30. 图层隐藏后元素不在画布渲染，但仍保留在列表中并可恢复；隐藏不影响其他顺序或音频配置。
31. 图层操作不会影响其他页面的元素顺序。
32. 页面保留独立的 `appearanceOrder`，播放顺序单独维护全部正文元素的顺序及展示方式。
33. 播放顺序编辑不依赖图层顺序，不提供 C 端播放执行、时间轴或多轨配置。
34. `标准互动 1` 为禁用占位；题不通过该入口创建，互动不可编辑且不产生互动数据。
35. MVP 不提供锁定、组合、动效时间轴和动效预设。

### 扩展边界

31. 数据结构为每页最多一个动效资源预留字段，未来可配置循环/单次播放和触发方式。
32. 数据结构为互动答题等点击交互预留扩展类型或配置字段，但 MVP 只实现静态题元素，不实现互动具体操作。
33. 一本书只允许选择中文或英文一种语言，不出现双语编辑字段；语言模型保留后续扩展空间。
34. MVP 不包含 C 端播放态、统一预览、导出、发布和审校区功能。
35. 未来进入审校态时，右侧可以动态增加审校区，动画书区域需要自动左移；生产态布局不得依赖固定右侧占位。
36. 顶部可以切换教研人员和制作人员，切换后使用同一份本地编辑状态。
37. 教研人员可以创建图文混排的图片、动效和音频需求槽位。
38. 制作人员只能查看需求和上传对应产物，不能修改文字、页面结构、图层或顺序。
39. 制作人员可以移动/缩放图片和动效，并调整气泡位置、尺寸及指向。
40. 动效只进行静态呈现，不出现播放、时间轴和触发配置。

## 风险与待确认项

- **出现顺序的实际表现**：目前定义为可排序的元素列表，具体是只保存顺序，还是要在 C 端由统一播放引擎执行，需要与统一播放方式对齐。
- **播放顺序的执行方式**：本文只定义编辑和排序，不定义并行播放、暂停、重播和跨页衔接规则。
- **上传约束**：图片和音频的文件类型、大小、时长、分辨率及素材库能力待确认。
- **文本样式**：字号、字体、颜色、对齐、行高、描边等编辑能力尚未在本需求中锁定；本轮仅锁定三类标注展示样式。
- **标注内容校验**：本轮仅校验字符范围和删除确认，拼音、翻译、讲解和注释的内容格式/字数限制待确认。
- **元素变换能力**：当前明确移动和尺寸调整；旋转、裁剪、透明度和吸附线是否需要，待交互设计阶段确认。
- **正文最小页数**：删除页面时的最小页数和空书规则待确认。
- **动效产物规格**：本期接受图片或视频文件并以静态占位/文件卡片展示，后续再确认统一的动效编码、首帧和尺寸规范。
- **互动扩展**：本轮题已作为独立静态元素落地；后续互动答题的事件、反馈、跳转和结果模型仍待业务方案确认。
- **语言选择时机**：语言是在创建动画书时选择，还是在设置中修改，待确认；MVP 不支持同书双语。
- **审校态**：本期不设计审校区内部功能，只保留“动态出现、主区域左移”的布局约束。
- **本地演示边界**：本期按纯前端 Demo 处理，不把自动保存、服务端持久化、接口错误和真实权限鉴权作为验收条件；角色切换和需求产物状态只存在于当前 Demo 会话。
- **富文本实现边界**：本期支持段落、粗体、斜体、列表、链接、图片和图片说明，不扩展为完整文档编辑器。

## 2026-09-04 封面固定化与封面语音

- 封面仅支持左右布局、全屏布局；布局切换显化在吸顶工具栏下方、画布外的独立空白区域，仅教研端可切换，制作端只展示当前布局。
- 封面元素的位置、尺寸、字体和数量固定，不支持拖拽、缩放、旋转、增删、字体格式化或图层排序；封面不显示正文添加工具、图层顺序入口、浮层或配置面板，键盘删除也必须被拦截。
- 左右布局固定使用 640×360 编辑画布中的图片 `x=95.33、y=67、226×226` 与文字列 `x=331.33、y=90、213.33×180`；对应 1920×1080 数据坐标分别为图片 `x=286、y=201、678×678`、文字列 `x=994、y=270、640×540`。
- 左右布局的四个文字输入位独立保存为 `coverField=title/topic/wordCount/fiction`：标题使用 PingFang SC Semibold 20px/30px，三条元信息使用 13.33px/20px，标签、值和圆点位置固定；仅允许修改四个位的文字内容，不能创建或合并文本框，且不支持动效。
- 全屏布局不渲染任何文字，仅渲染一个固定铺满 640×360 编辑画布的媒体模块（数据坐标 1920×1080），媒体为图片或动效；媒体类型通过“图片/动效”标签下拉切换，切换前确认并清空旧媒体及其不兼容需求。
- 全屏媒体复用常规图片/动效的需求编辑、上传、替换、删除和失败重试能力，但封面媒体尺寸、位置、旋转和图层均不可调整；左右布局只保留图片。
- 封面语音是每个封面唯一的页面级音频需求，画布下方只保留一个入口。收起态文案为“封面语音”（100×32），展开态标题为“讲解语音”，媒体标签为“语音”；需求胶囊可展开/收起，展开后显示“需求”和“补充”两行富文本。
- 教研端可编辑封面语音需求与补充需求；制作端只读查看需求并可点击或拖拽上传音频。上传类型错误或读取失败时保留原音频，显示失败状态并支持重试。
