# 交互说明：项目封面生成器改版

## 页面结构

```text
固定顶栏
┌────────────────────────────────────────────────────────────┐
│ 返回  封面图生成工具                         JPG  清晰度  下载 │
├───────────────┬────────────────────────────────────────────┤
│ 左侧配置导航   │ 中部实时预览工作区                         │
│ 独立滚动       │ 画布固定居中，不承担页面滚动                 │
└───────────────┴────────────────────────────────────────────┘
```

- 顶栏：返回、页面标题、固定 JPG 输出标识、1x/2x 高清选择、下载。
- 左侧：基本信息、背景、素材三组配置。左侧内容独立滚动，资源面板自身有最大高度。
- 中部：预览标题、画布尺寸信息和真实 Canvas 预览。预览区固定在工作区内，不因左侧列表变长而移动。

## 信息架构

1. 基本信息：封面类型、标题、项目组布局方向、存储标签。
2. 背景：背景色系、背景纹理。
3. 素材：人物形象和人物分类。
4. 导出：固定 JPG、清晰度和下载。

## 操作清单

| 操作 | 触发 | 逻辑与反馈 |
| --- | --- | --- |
| 切换封面类型 | 点击类型按钮 | 更新字段规则，清空不适用的人物选择；按钮出现选中态 |
| 输入标题 | 输入单行文本 | 150ms 防抖更新预览；不支持 Enter/手动换行，只按当前布局文字框自动换行；显示有效字数与超限提示 |
| 切换布局方向 | 点击方向按钮 | 仅项目组中文标题显示；更新预览布局 |
| 切换存储标签 | 点击 Switch | 仅项目组可用；更新预览左上角标签 |
| 展开 / 收起面板 | 点击面板标题 | `aria-expanded` 与视觉箭头同步；默认只展开背景色 |
| 选择背景色系 | 点击颜色系卡片 | 颜色系卡片整体是唯一交互入口，色阶块只展示参考；更新摘要与预览 |
| 选择纹理 | 点击纹理缩略图 | 选中边框与勾选标记同步；“无”清空纹理 |
| 切换人物分类 | 点击分类 Tab | 只切换当前资源集合，不清除已经选择的人物，除非封面类型发生变化 |
| 选择人物 | 点击人物缩略图 | 选中边框与勾选标记同步；预览更新 |
| 选择清晰度 | 点击 1x / 2x | 下载时按对应倍率重新渲染 Canvas |
| 下载 | 点击下载按钮 | 字体未完成或导出中禁用；完成后下载 JPG 文件 |

## 状态设计

- 默认：背景色面板打开，纹理和人物面板收起；预览显示默认色块。
- 字体加载中：左侧显示轻量提示，下载按钮不可用。
- 输入超限：输入框显示错误边框，计数变为错误色；不使用弹窗打断输入。
- 未选择资源：摘要为“无”或“未选择”，资源面板显示明确空选项。
- 图片加载失败：资源缩略图显示“加载失败”占位，不影响其余操作。
- 导出中：下载按钮显示“导出中...”并禁用，避免重复下载。
- 无权限：当前演示页没有权限分支；未来接入资源库时补充入口级无权限状态。

## 关键交互说明

### 标题与自动换行

- 标题控件使用单行输入框，粘贴或输入产生的 `\r/\n` 会被移除，不将 Enter 解释为强制换行。
- 项目组中文标题按 1–2、3、4、5–6、7–8 字匹配 Figma 组件；中文单字兜底使用 2 字组件。
- 英语标题匹配 `L + 数字` 或“最多 1 个中文前缀 + 可选半角空格 + L + 数字”，例如 `L1`、`新L1`、`新 L2`。匹配后隐藏布局方向和人物选择，使用英语专属组件。
- 超出上限仍允许继续输入与下载，但输入框显示错误边框和“超出限制”。

### Figma 组件几何

- 项目封面使用固定人物框 `(54,42,531,300)` 与 280 px 标题样式。
- 项目组中文组件的人物框均为 223×303 px；方向和字数只决定文字框及人物框位置，不能通过用户拖拽改变。
- 「存储」标签始终固定在 `(26,26)`，尺寸 116×57，文案不可编辑；Switch 只控制显示/隐藏。
- 英语组件没有人物素材，使用布局自带的浅色装饰图形和英语标题字体。

### 背景色选择

- 将 15 个颜色系以紧凑网格展示。
- 每个颜色系展示名称和 6 个色阶色块，但只有外层颜色系按钮可以点击。
- 项目封面和项目组封面继续使用原有固定色阶，不增加新的色阶业务字段。
- 选中状态通过蓝色描边、外环和文字状态共同表达，不依赖单个色块颜色判断。

### 资源选择

- 纹理和人物面板采用分类 Tab + 固定最大高度网格。
- 网格使用自适应列数，素材数量增加时只在面板内部滚动。
- 缩略图只承担识别和选择，不显示长名称；完整名称通过 `title` 和 `aria-label` 提供。
- 资源图片加载失败时保留按钮位置，避免布局跳动。

### 导出反馈

- 页面只显示固定的 JPG 输出状态，不提供格式切换。
- 下载按钮显示主操作层级，清晰度使用次级分段选择。
- 下载完成不额外增加弹窗或 toast，保持当前演示页的轻量行为；若后续接入真实接口，再补充成功与失败反馈。

## 组件复用建议

- 复用现有 `Switch` 组件处理存储标签。
- 复用现有 `CoverPreview`、`drawCover`、`layoutMatcher` 和资源 token，不改变画布渲染职责。
- 按钮、输入、圆角、品牌色和密度沿用 `docs/01-foundations/` 与 `docs/02-components/`。
- `ColorPicker` 继续作为颜色选择组件，但从“色阶按钮网格”调整为“颜色系卡片网格”。
- `ThumbnailGrid` 继续作为纹理和人物选择组件，但增加分类切换、固定高度和加载失败占位。

## 研发注意事项

- 桌面端工作区使用 `height: 100dvh` 与 `overflow: hidden`，仅左侧配置容器允许 `overflow-y: auto`。
- 900px 以下切换为单列：左侧配置先展示，预览区使用独立固定高度；不得出现横向溢出。
- 保留 `prefers-reduced-motion` 下的静态状态，交互过渡只使用 opacity、transform 或颜色。
- 所有图标按钮必须有 `aria-label`；颜色系、缩略图和清晰度控件必须表达 `aria-pressed` 或等效选中语义。
- 不引入新依赖，不修改全局 Vite 配置、路由、接口或数据库。

- 当前版本沿用“标题超限仍可下载”的旧行为。若业务希望强制拦截，需要在下一轮单独确认。
- 后续素材数量预计会增长，但素材搜索、收藏、分页和权限不在本次改版范围内。
- 项目组背景色应以需求规定的第 1 阶为准，还是以 Figma 示例中的第 4 阶为准？
- 项目组纹理应使用需求规定的 35% 铺满，还是 Figma 示例的低透明度平铺/混合模式？
- 项目组标题颜色采用 Figma 的白色，还是按背景色阶自动匹配？
- 项目封面纹理以需求的 contain 规则为准，还是以 Figma 示例的铺满画布为准？
