方案状态：第三稿已实现，作为产品验收与后续迭代的视觉基线。

确认稿：`docs/designs/cover-generator-playful-redesign-approved.png`

## 2026-09-03 实现说明

- 颜色面板移除顶部当前颜色汇总卡和色数徽标，只保留背景色块网格；网格下方实时展示当前所选背景色的十六进制色值。
- 文字颜色恢复可编辑，使用与背景色板一致的纯色块网格，不显示选项可见文案；候选项仍通过 `aria-label` / `title` 提供颜色识别信息。
- 背景色切换和随机生成时自动匹配当前背景下的默认可读字色；用户可在满足最低对比度门槛的候选色块中手动选择，选择后预览和导出同步更新。
- 文字颜色说明文案为“已自动匹配清晰易读的字体颜色，可手动调整。”
- 清晰度控件显示为“1x”和“2x”，仅精简“高清”字样；2x 导出倍率和尺寸规则不变。

## 2026-08-25 设计基线：双模式与真实比例预览

- 视觉方向以用户提供的参考图为准：保留轻松、童趣、纸艺/软质感和教育产品亲和力，不再以“避免幼稚”为目标；童趣装饰只出现在工具界面背景和控制面板外围，不侵入真实封面 Canvas。
- 设计稿优先重构右侧封面展示区；左侧不显示模式入口，使用“随机生成”按钮和背景、纹理、角色入口直接表达两类能力。
- 右侧直接展示真实横版 Canvas：项目封面 640×360，项目组封面 675×384；容器只负责居中和缩放，不为封面增加透视、厚度、拟物边框或会被误认为导出内容的装饰。
- 「随机生成」是默认主路径：输入标题后点击一次即可生成。角色、背景、纹理与字体全部取自项目现有素材和规则。
- 背景、纹理和角色入口承载直接自定义：用户无需切换模式即可打开面板连续选择；用户界面统一使用“角色”，历史代码字段和素材文件名可继续保留。
- 顶部继续提供 1x / 2x 和“导出 JPG”，导出尺寸以真实 Canvas 为准。

## 页面结构

```text
固定顶栏
┌────────────────────────────────────────────────────────────┐
│ 图形 Logo  JOJO Labs                         清晰度  导出 JPG │
├───────────────┬────────────────────────────────────────────┤
│ 标题 + 随机按钮  │ 工作台右上：封面类型下拉                    │
│ 资源入口 + 设置  │ 下方：真实横版 Canvas                       │
└───────────────┴────────────────────────────────────────────┘
```

- 顶栏：返回、图形 Logo、JOJO Labs、1x/2x 选择和“导出 JPG”。
- 左侧：标题后直接显示“随机生成”主按钮，随后是颜色、纹理、角色资源入口；图文方向和存储标签常驻展示。左侧内容独立滚动。
- 中部：上方右侧放置封面类型下拉菜单，下方只展示真实 Canvas 预览，不再显示尺寸或“Canvas 实时预览”辅助文案；封面边界清楚可见，预览区固定在工作区内，不因左侧列表变长而移动。Canvas 内部按 2 倍像素密度绘制，但显示尺寸不变。

## 信息架构

1. 核心任务：封面类型、标题、随机生成按钮和直接自定义入口。
2. 随机生成：单一高优先级生成按钮，不提前暴露素材选择成本。
3. 自定义：颜色、纹理、角色；点击资源入口呼出二级面板。
4. 结果预览：真实横版 Canvas、固定比例和明确边界。
5. 导出：固定 JPG、1x/2x 清晰度和下载。

| 切换封面类型 | 点击右侧工作台上方类型选择 | 保留背景、纹理、方向和存储标签，为新类型选择有效角色；从项目组切换到项目时标题取前两个字符；标题不符合新类型时就地提示 |

## 状态设计

- 默认：标题、随机按钮和资源入口可直接操作，预览显示默认组合。
- 随机生成中：生成按钮显示进度并禁用，预览保留上一张有效封面，避免闪烁空白。
- 随机生成失败：保留上一张有效封面，在按钮附近显示可重试错误，不影响继续直接自定义。
- 字体加载中：左侧显示轻量提示，下载按钮不可用。
- 输入超限：输入框显示错误边框，计数变为错误色；不使用弹窗打断输入。
- 未选择纹理：纹理摘要为“无”，面板显示“无纹理”选项；适用人物布局不提供空人物选项。
- 图片加载失败：资源缩略图显示“加载失败”占位，不影响其余操作。
- 导出中：下载按钮显示“导出中...”并禁用，避免重复下载。
- 无权限：当前演示页没有权限分支；未来接入资源库时补充入口级无权限状态。
- 信息精简：不显示预览标题说明、画布标签、固定比例/格式提示、重复尺寸说明、成功下载提示或“可直接导出”状态；错误与标题校验反馈继续显示。

## 关键交互说明

### 随机生成与直接自定义

- 随机生成不调用新的图像生成服务，只在本地既有角色、颜色和纹理资源之间组合；字体、图层顺序和几何布局沿用 Canvas 规则。
- 标题为空或不合法时，随机生成按钮禁用，并复用标题字段的就地校验；不弹出二次确认。
- 每次从颜色、纹理和角色中各选择一项；项目组中文标题再从两个图文方向中随机选择；最多尝试 12 次避免与上一结果完全相同，且不跨刷新保存随机历史。
- 直接选择资源时，以当前随机结果作为自定义起点，避免用户从空状态重新选择。
- 自定义后仍可随时点击“随机生成”；只有点击该按钮才会产生新组合。

### 真实比例预览

- 项目封面固定 640×360，项目组封面固定 675×384；CSS 只通过统一 scale 或等比宽高约束缩放 Canvas。
- 预览 Canvas 的内部绘制尺寸为对应逻辑尺寸的 2 倍，CSS 宽高仍按逻辑尺寸展示；提升预览清晰度不得改变封面在工作区中的显示大小。
- 预览不得使用透视、旋转、厚边框或近方形拟物卡片。Canvas 外部阴影、棋盘格或工作台背景必须与导出边界保持清晰分离。
- 右侧可比左侧占据更多面积，画布在可用区域内尽量大，但不得为了填满空间裁切封面。
- 预览区不显示尺寸辅助标签；真实 Canvas 的内部尺寸仍固定为项目 640×360、项目组 675×384，不叠加到导出内容中。

### 视觉语言

- 沿用参考图的浅蓝工作台、奶油白配置卡、圆润控件、纸张纹理、柔和阴影和少量云朵/胶带/草地等教育场景装饰。
- 品牌蓝继续承担主要按钮和选中态；装饰色使用低饱和黄、绿、橙作为点缀，避免与状态色混淆。
- 控件仍需保持清晰、可实现和可访问；童趣来自材质、插画和节奏，不通过夸张字号、复杂拟物或降低信息对比度实现。
- 右侧真实封面始终是视觉主角；外围装饰不得遮挡画布、改变画布比例或被误认为导出内容。
- 配置卡分组之间通过留白和资源入口边界表达层次，不使用本轮移除的两条横向分割线。

### 标题与自动换行

- 标题控件使用单行输入框，粘贴或输入产生的 `\r/\n` 会被移除，不将 Enter 解释为强制换行。
- 从项目组切换到项目封面时，当前标题截取前两个字符；例如“初中语文”切换后为“初中”，切回项目组不自动恢复原始长标题。
- 项目组中文标题按 1–2、3、4、5–6、7–8 字匹配 Figma 组件；中文单字兜底使用 2 字组件。
- 英语特殊标题严格匹配“一个 ASCII 字母 + 一个数字”，或“新 + 一个 ASCII 字母 + 一个数字”，例如 `L1`、`A2`、`z9`、`新L1`、`新A2`。允许首尾空格；内部空格、多位数字和其他前缀均不匹配。渲染时字母统一转为大写。匹配后隐藏布局方向和人物选择；人物配置不参与预览或导出，使用英语专属组件。
- 特殊标题的中文前缀使用 `FZLanTYJW_Da`，字母数字主体使用 `MohrRounded-Heavy`；普通项目组标题使用 `FZLanTYJW_Da`。
- 超出上限仍允许继续输入与下载，但输入框显示错误边框和“超出限制”。

### Figma 组件几何

- 项目封面使用固定人物框 `(54,42,531,300)` 与 280 px 标题样式。
- 项目组中文组件的人物框均为 223×303 px；方向和字数只决定文字框及人物框位置，不能通过用户拖拽改变。
- 「存储」标签始终固定在 `(26,26)`，尺寸 116×57，文案不可编辑；Switch 只控制显示/隐藏。
- 英语组件没有人物素材，使用英语标题字体和背景纹理；不再绘制英文字母装饰背景。

### 背景色选择

- 将现有具体色阶按原有顺序平铺为紧凑色板。
- 每个小色块都是独立的选择按钮，保留色系、阶数和色值的 `aria-label` / `title`。
- 项目封面和项目组封面继续使用所选具体色阶，不增加新的色阶业务字段。
- 色板小色块不显示阶数数字，但在 `aria-label` / `title` 中保留色系、阶数和色值信息。
- 背景色选中状态只通过明显描边表达，不显示勾选图标；色板下方只展示当前所选色值。文字颜色按背景色阶自动匹配默认可读颜色，同时保留满足最低对比度门槛的手动候选。

### 文字颜色规则

- 背景第 4–6 阶使用白色文字。
- 背景第 1–3 阶使用同色相第 6 阶最深色文字，例如 `#F5F4F4` 使用 `#404040`，`#F3EBFC` 使用 `#4E2680`。
- 背景色切换和随机生成会重新自动匹配默认字色；封面类型切换在背景不变时保留用户当前字色。
- 用户可以在当前背景下满足最低对比度门槛的候选色块中手动选择；选中后立即更新预览与导出。

### 资源浮层

- 桌面端浮层使用固定定位，贴近触发按钮右侧并限制在视口内，不被侧栏滚动容器裁切。
- 点击空白或按 Esc 关闭；关闭后焦点回到对应一级菜单。
- 选择颜色、文字颜色、纹理或人物后不自动关闭，支持连续试选；关闭面板后焦点回到对应一级菜单。
- 900px 以下使用内嵌面板，面板宽度不超过侧栏内容区，不产生横向滚动。

### 资源选择

- 纹理和角色面板采用分类 Tab + 固定最大高度网格；角色分类 Tab 超出面板宽度时支持普通横向滚动。
- 分类 Tab 隐藏原生滚动条，但保留横向触摸、触摸板和滚轮滚动能力；滚动到最左端或最右端后保持边界，不跳转到另一端。
- 分类 Tab 不创建重复分类；辅助技术只读取一组真实分类，键盘焦点不落到虚拟节点上。
- 网格使用自适应列数，素材数量增加时只在面板内部滚动。
- 角色网格不提供“无角色”选项；普通项目/项目组中文标题默认选中当前分类的首个角色，用户只能在现有角色素材之间切换。
- 缩略图只承担识别和选择，不显示长名称；完整名称通过 `title` 和 `aria-label` 提供。
- 资源图片加载失败时保留按钮位置，避免布局跳动。

### 导出反馈

- 页面只显示固定的 JPG 输出状态，不提供格式切换。
- 下载按钮文案为“导出 JPG”，显示主操作层级；清晰度使用次级分段选择；1x/2x 都按对应物理像素重新渲染。
- 下载完成不额外增加弹窗或 toast，保持当前演示页的轻量行为；若后续接入真实接口，再补充成功与失败反馈。

### 工作台类型与方向控制

- 封面类型控制放在右侧工作台上方、预览区右上侧，使用紧凑下拉选择；固定顶栏不重复展示；预览区不显示额外尺寸标签。
- 预览工作区不展示“可直接导出”状态；下载按钮继续使用禁用态和 title 提示表达不可导出的原因。
- 图文方向使用 Segmented 分段控制器；两个选项均显示统一的单一 SVG 封面缩略图，图片区与文字区按“左图右文 / 左文右图”镜像排列，不新增依赖。
- 封面类型控制通过当前值、展开选项和 focus 状态表达选择结果，不依赖增大容器高度；工作台收窄时随预览区进入单列布局。
- 左侧工作区桌面端约 400px，内部纸艺配置卡约 332px；视口收窄时按 900px 断点切换为单列。

### 资源入口预览

- 颜色、纹理、角色一级菜单的左侧视觉区域统一为相同尺寸的预览框，尺寸控制在不挤压标题的范围内。
- 颜色入口显示当前背景色块；纹理入口显示当前纹理小图；角色入口显示当前角色小图。
- 预览框直接取代通用 Palette / Image / Users 图标；入口卡片不再显示颜色阶数、纹理名称、角色分类等可见摘要描述。
- “无纹理”等未选择状态使用同尺寸的轻量空态框，资源名称继续通过 `aria-label`、`title` 或等效辅助信息提供。
- 资源入口仍是按钮，点击后打开原有资源面板；选中态、面板开关、键盘焦点和失败占位逻辑保持不变。

## 组件复用建议

- 复用现有 `Switch` 组件处理存储标签。
- 复用现有 `CoverPreview`、`drawCover`、`layoutMatcher` 和资源 token，不改变画布渲染职责。
- 按钮、输入、圆角、品牌色和密度沿用 `docs/01-foundations/` 与 `docs/02-components/`。
- `ColorPicker` 继续作为颜色选择组件，调整为紧凑平铺色板；具体色阶按钮仍可直接选择，视觉上不显示阶数数字或勾选图标。
- `TextColorPicker` 复用背景色板的纯色块网格、描边选中和 focus 规则，不显示选项可见文案；候选色块继续通过 `aria-label` / `title` 提供识别信息。
- `ThumbnailGrid` 继续作为纹理和角色选择组件，支持普通分类切换、横向滚动、固定高度和加载失败占位。

## 研发注意事项

- 桌面端工作区使用 `height: 100dvh` 与 `overflow: hidden`，仅左侧配置容器允许 `overflow-y: auto`。
- 900px 以下切换为单列：左侧配置先展示，资源浮层改为内嵌，预览区使用独立固定高度；不得出现横向溢出。
- 保留 `prefers-reduced-motion` 下的静态状态，交互过渡只使用 opacity、transform 或颜色。
- 所有图标按钮必须有 `aria-label`；颜色系、缩略图和清晰度控件必须表达 `aria-pressed` 或等效选中语义。
- 不引入新依赖，不修改全局 Vite 配置、路由、接口或数据库。
