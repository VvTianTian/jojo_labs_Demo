# 动画书生产工具双角色协作交互说明

## 2026-09-07 正文对话框自适应、默认高度、横向缩放与三角旋转

本轮依据 Figma 节点 `12400:63635` 更新正文页对话框；封面不使用本规则。外观继续复用米色外层、白色描边、浅米色内层、圆角和留白。

### 新增与编辑

- 教研人员点击工具栏“对话”后，在当前正文页新增一个空气泡，目标画布初始约为 `298×120`，编辑视图约为 `99×40px`。
- 新气泡默认选中但不自动进入文字编辑、不聚焦输入框；空内容只显示占位“请输入对话”，不写入 `content`。双击气泡后进入编辑态并聚焦，失焦后保留内容并退出编辑。
- 气泡文字使用 `16px` 字号和 `24px` 行高，显式换行保留为内容换行，自动换行不写入额外字符。

### 内容与尺寸状态

- 新气泡初始 `widthMode=auto`。第一次把空内容输入为非空时，按当前字体、留白和最长显式行测量自然宽度，并同时计算高度；宽度受画布可用宽度限制，完成后 `widthMode` 进入 `manual`。
- `widthMode=manual` 后，输入、粘贴、显式换行、自动换行和清空均保留当前宽度，只重新计算高度；气泡 `y` 坐标不变。清空后高度回到单行最小高度。
- 文本较长时按当前宽度自动换行。内容自然最大宽度是最长显式行的宽度；横向拉大不能超过自然最大宽度与画布可用宽度的较小值。

### 横向缩放

- 气泡选中后只显示左、右中点两个 `ew-resize` 手柄，不显示上、下或四角手柄，因此不支持垂直手动缩放。
- 拖动左手柄时固定右边缘，调整 `x + width`；拖动右手柄时固定左边缘，调整 `width`。两侧都受画布边界和 Figma 空框最小宽度约束。
- 横向缩放过程中实时换行并自适应高度；宽度改变后不自动恢复自然宽度。制作人员与教研人员都可进行该几何操作。

### 三角指向

- 三角控制点可从气泡边缘拖拽，系统以指针相对气泡中心的方向计算角度，并将落点投影到矩形边缘；上、下、左、右和四角均可定位。
- 使用 `tailAngle` 保存方向，`0°` 向右，顺时针递增，始终归一化到 `[0,360)`；三角视觉旋转与保存角度一致。
- 三角视觉尺寸较原默认值适度放大，绘制层级低于气泡内层内容，避免遮挡台词。
- 三角控制点保留 `role=slider` 语义：右/下方向键顺时针增加 1°，左/上方向键减少 1°，Shift+方向键按 15° 调整，Home 设置 `0°`，End 设置 `359°`；属性面板可输入角度进行精细调整。
- 旧数据中的 `direction`、`tailX`、`tailY` 只在加载时转换为 `tailAngle`，转换后不再驱动交互。

### 双角色状态

- `教研人员`：可双击编辑文字、横向缩放气泡和拖拽/键盘调整三角。
- `制作人员`：气泡文字只读，双击不进入编辑；仍可横向缩放和拖拽/键盘调整三角。
- 切换角色、切换页面或切换下方页签不会重置气泡的文字、宽高、`widthMode` 或 `tailAngle`。

## 2026-09-07 空白初始态

- 首次进入 Demo 时保留“封面、正文 1”。封面只清空已填写的数据，保留固定模板元素和空需求绑定；正文不预置元素、需求槽位或顺序项。
- 空封面缩略图显示“暂无封面”，空正文缩略图显示“暂无内容”；画布保留 16:9 编辑区域和现有工具入口。
- 初始不选中画布元素、不打开文本编辑态。封面左右布局保留左侧固定图片占位和右侧标题、绘本主题、阅读字数、虚构/非虚构四个空输入位，教研人员可点击填写文字内容；图片与文字位置、尺寸固定，不响应拖拽和缩放。全屏布局只有铺满画布的固定媒体模块，不显示文字。正文通过既有工具主动创建内容。
- 该初始态不改变后续新增页面、元素、需求编辑、上传、图层和播放顺序的交互规则。

### 初始页数调整

- 空白初始态只保留 1 个正文页；用户仍可通过“添加页面”创建更多正文页。

## 2026-09-07 图片/动效需求与元素同层级

- 图片/动效与其需求卡作为同一视觉元素组渲染，共享所属元素的画布 `z-index`；需求卡可以覆盖自己的图片/动效内容，但不得越过其他元素的正常图层。
- 不因元素被选中而临时提升需求卡或图片/动效的层级；气泡、文字等更高图层可以覆盖需求卡。
- 未上传图片/动效产物时，需求默认展开为展示态；产物上传成功后默认收起；点击“需求”按钮可随时切换展开和收起。
- 需求被更高图层完全覆盖时，通过图层工具中的需求入口或侧栏需求面板访问，不自动改变元素图层顺序。

## 2026-09-04 制作人员文本框几何权限

- 制作人员视图不显示画布制作工具栏。
- 制作人员不能编辑正文文本内容，但可以移动和缩放文本框；双击文本框不进入编辑态。

## 2026-09-03 题元素与题 Tab MVP

本轮依据 Figma 文件节点 `12147:38432`、题卡 `12173:77675` 和页码组 `12283:123934`，在现有 `/animation-book` 生产态中实现静态题元素与题 Tab；互动已在下述 2026-09-08 补充中接入。

### 页面、画布与页码

- 题入口只在正文页出现，封面不显示题入口；每个正文页最多存在一个题。
- 题新增后自动选中并打开下方“题”Tab。题卡固定在画布右上区域，按 1920×1080 目标画布保存为 `x=1044`、`y=198`、`width=540`、`height=612`，640×360 编辑画布按比例缩放。
- 题卡不响应移动、缩放或画布内文本编辑；题卡被选中时只显示选中边框，不显示移动/缩放手柄。
- 页码位于画布右下角，正文页显示 `当前页/正文总数`；本页存在题时在页码右侧显示“题”徽标。题被隐藏后题卡消失，但徽标不消失；封面和无题正文页不显示徽标。

### 工具栏与互斥入口

- 正文页点击“题”：无题时创建题并打开题 Tab；已有题时只重新选中已有题并打开题 Tab，不创建第二个题。
- 正文页点击“互动”：无题或互动时创建投票互动，选中并打开“题”Tab；已有互动时重新选中并打开配置。题与互动互斥，存在其中一种时另一入口置灰。
- 封面上的“题”和“互动”入口均不可操作。

### 题 Tab

- 题 Tab 始终显示计数 `1`，包含头部信息、题目区、答案区和标签区，不显示解析区。
- 本轮可编辑字段只有题干文字、文本选项和正确答案；输入内容实时回显到画布题卡，画布题卡本身不可直接编辑。
- 默认创建 A-D 四个空文本选项，选项数量限制为 2–4；达到 4 项时禁用“添加选项”，达到 2 项时禁用删除选项。
- 每个选项使用“设为正确选项”按钮切换正确答案，允许同时选择多个，默认没有正确答案。
- 移除文字/图片/听力材料区、解析区，以及“文本选项 / 图片选项”切换控件；文本选项直接编辑。题干语音、答案区、标签区和引用/保存操作保留只读或禁用的视觉占位。

### 图层、删除与角色

- 题与其他页面元素一样出现在教研人员图层中，可选择、隐藏和恢复；隐藏只改变画布渲染，不移除元素、图层顺序或页码徽标。
- 题不加入播放顺序列表，也不加入音频列表、出现播放逻辑或 C 端互动数据。
- 题被选中时按 `Delete` 或 `Backspace` 始终打开二次确认。点击“取消”、按 `ESC`、点击遮罩或关闭弹窗均不删除；点击确认后移除题元素和对应图层顺序。
- 制作人员可以查看题卡、题 Tab 和题内容，但题干、选项、正确答案、图层和删除操作均为只读；切回教研人员后恢复编辑。

## 2026-09-03 图/动效需求卡交互优化

本轮依据 Figma 节点 `12244:83447` 调整图片、动效画布卡片及其需求入口；不改变图片/动效的初始位置、固定初始宽高、移动和缩放能力。

### 状态与操作

每个图片或动效需求在当前页面独立维护临时 UI 状态：

| 状态 | 画布表现 | 进入方式 | 离开方式 |
| --- | --- | --- | --- |
| 收起 | 仅显示“需求”按钮 | 展示态点击自身按钮 | 教研/制作点击按钮进入展示 |
| 编辑 | 显示富文本输入框和 Figma 风格工具栏，输入框获得焦点 | 教研单击展示态需求内容 | 输入框失焦进入展示；再次点击按钮立即收起 |
| 展示 | 显示富文本只读内容；空内容显示“未填写需求” | 编辑态失焦；新建或已有空需求默认进入 | 点击自身“需求”按钮收起；教研单击展示内容进入编辑 |

- 图片/动效置入后默认展开空需求展示态，但不自动激活输入框、不聚焦。
- 教研人员在收起态点击“需求”按钮先展开展示态；展示态单击需求内容区才进入编辑态并自动聚焦，编辑态点击按钮立即收起，已输入内容保留。
- 已填写需求和“未填写需求”均可通过展示内容进入编辑；制作人员端保持只读，不显示编辑器。
- 需求按钮固定在图片/动效框架左下角；展示态和编辑态的需求内容面位于按钮右侧，默认不超出框架边界。
- 内容面宽度随图片/动效框架的几何宽度同步伸缩，优先保持当前默认宽度；空间不足时在框架内收缩到可用最小宽度。
- 展示态在当前页面内常驻。点击其他图片、动效、其他画布元素或画布空白，不关闭已有展示态；同一页面允许多个展示态同时存在，但同一时间只保留一个编辑态。
- 切换页面或角色时清除当前页面的临时展开状态；切回后空需求仍按默认展示态显示，已填写需求默认收起，需求正文不丢失。
- 需求按钮不切换底部配置页签；画布元素选中和图片/动效置入也不改变当前底部页签。

### 角色差异

- `教研人员`：可编辑需求正文，支持富文本工具栏；需求正文由用户手动点击入口后编辑。
- `制作人员`：只能展开/收起并查看需求正文；不可编辑需求或文本内容、不可看到富文本工具栏，但保留文本框、图片/动效移动和缩放能力。

## 2026-09-04 制作人员图片框直接上传

- 制作人员切换角色后，图片元素的内容区域变为可直接上传区域；点击图片内容或空图片框打开图片文件选择器。
- 图片需求区域继续阻止事件冒泡，点击“需求”按钮仍只负责展开或收起需求，不触发上传。
- 制作人员 Hover 或聚焦图片框时显示上传、删除操作；上传按钮打开图片选择器，删除按钮只清空图片产物并保留图片框、需求、位置和尺寸。
- 上传成功后图片在图片框内使用 `contain` 等比例完整展示；图片框仍支持移动和缩放，拖拽移动不会误触发上传。
- 未上传图片时需求默认展开；已有图片时需求默认收起；用户点击“需求”按钮后可再次切换。

### 焦点、层级与响应式

- 富文本工具栏属于需求编辑区域，点击工具栏按钮不触发失焦提交；焦点离开编辑区域后统一转展示态。
- 需求展示/编辑浮层位于元素内容区底部，按 Figma 的灰蓝卡片、22px 胶囊按钮、蓝色选中边框和富文本内容区呈现，并通过元素层级保证内容不被其他元素遮挡。
- 需求卡与所属图片/动效处于同一画布图层；需求内容仅在所属视觉元素组内部叠加，不使用画布级置顶层，也不因选中状态提升层级。更高图层元素可以覆盖需求卡，覆盖时通过图层工具或侧栏需求面板访问。
- 编辑态的输入面板以独立内容面为边界，使用完整的蓝色描边和 10px 圆角；工具栏作为上方浮层，不参与输入面裁切，确保四角和四边在画布边缘、窄屏及元素重叠时完整可见。
- 教研展示态需求内容区提供可见焦点样式，支持 Enter / Space 进入编辑；制作人员展示内容不设置编辑焦点入口。
- 新增页面默认不创建文本元素，画布显示空白页状态；用户通过“文字”入口主动添加文本。
- 画布继续保持 16:9 比例；窄屏或元素较窄时需求内容面在框架内收缩，不改变元素几何比例。

## 2026-09-03 文本与领读语音补充需求优化

本轮依据 Figma 节点 `11816:68733`（领读语音需求弹窗）和 `12266:108109`（工作台页签）补充正文文本与领读语音交互；不改变封面文字、对话气泡字体层级或制作人员既有音频上传流程。

### 正文文本默认样式

- 正文 `TextElement` 默认渲染为 PingFang、16px、400、normal、24px（150%）。
- 文本浮动工具栏仍提供显式加粗、斜体、下划线、颜色和对齐操作；用户主动操作后保留对应显式样式。
- 封面文字和对话气泡不套用正文文本默认字体规则。

### 领读语音列表

- 仅列出当前页面的文本和对话元素，按 `page.elements` 写入顺序排列。
- 左侧显示总序号和类型编号；文本、对话分别独立递增，例如“文本1、对话1、文本2”。
- 台词文案以只读文本展示，不允许在列表内直接编辑；切换页面或角色后，列表根据同一份页面模型重新回显。
- 每项末尾显示“补”字按钮，按钮支持鼠标 Hover、键盘 Focus、明确的 `aria-label` 和 Tooltip。
- 台词文案承载区使用 `#D0DFE7`、10% 透明度（`rgba(208, 223, 231, 0.1)`）；列表项外层保持透明，不叠加背景色。

| 补充需求状态 | 按钮样式 | Tooltip |
| --- | --- | --- |
| 空或仅空白 | 灰色 | 暂无音频补充要求（如语气、音色等台词内容以外的要求） |
| 有内容 | 专业蓝 `#316CE3` | 显示 `voiceSupplement` 内容 |

### 补充需求弹窗

1. 教研人员点击某项“补”按钮，打开“领读语音需求”弹窗，并自动聚焦“补充”多行输入框。
2. 弹窗展示只读的“台词需求”，内容实时取当前文本/对话文案；该区域不可编辑。
3. 弹窗展示可编辑的“补充”多行纯文本输入框，用于填写语气、音色、语速等台词内容以外的需求。
4. 点击“确认”保存当前输入；输入为空或仅空白时保存为空，列表按钮恢复灰色状态。
5. 点击“取消”、右上角关闭按钮、遮罩，或按 `ESC` 均关闭弹窗且不保存本次编辑。
6. 弹窗打开期间，页面背景不可滚动；关闭后恢复原滚动状态。

## 2026-09-03 文本横向拖动与高度自适应

- 教研人员选中文本元素后，文本框左右中点显示横向缩放手柄；四角缩放手柄继续保留原有行为。
- 拖动左侧或右侧中点手柄时，仅沿水平方向调整文本框的位置和宽度；拖动过程中按新的宽度实时换行，并将文本框高度更新为内容所需高度。
- 文本框内容区域始终不显示滚动条；横向缩放完成后，文本、标注、字体样式、领读语音补充需求和音频配置保持不变。
- 横向拖动受画布边界和最小宽度限制；文本内容为空时仍保留可操作的最小高度。

## 2026-09-03 正文文本默认首行缩进

- 正文页 `TextElement` 默认使用 Figma `Paragraph indent = 32`，渲染为 `text-indent: 32px`，在 16px 正文字号下对应首行空两格。

## 2026-09-04 文本编辑占位、段落换行与光标稳定
