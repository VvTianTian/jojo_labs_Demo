# 动画书生产工具双角色协作交互说明

## 2026-09-03 题元素与题 Tab MVP

本轮依据 Figma 文件节点 `12147:38432`、题卡 `12173:77675` 和页码组 `12283:123934`，在现有 `/animation-book` 生产态中实现静态题元素与题 Tab；互动仍属于下一阶段能力。

### 页面、画布与页码

- 题入口只在正文页出现，封面不显示题入口；每个正文页最多存在一个题。
- 题新增后自动选中并打开下方“题”Tab。题卡固定在画布右上区域，按 1920×1080 目标画布保存为 `x=1044`、`y=198`、`width=540`、`height=612`，640×360 编辑画布按比例缩放。
- 题卡不响应移动、缩放或画布内文本编辑；题卡被选中时只显示选中边框，不显示移动/缩放手柄。
- 页码位于画布右下角，正文页显示 `当前页/正文总数`；本页存在题时在页码右侧显示“题”徽标。题被隐藏后题卡消失，但徽标不消失；封面和无题正文页不显示徽标。

### 工具栏与互斥入口

- 正文页点击“题”：无题时创建题并打开题 Tab；已有题时只重新选中已有题并打开题 Tab，不创建第二个题。
- 正文页点击“互动”：当前没有题时保持可点击，显示提示“下一版本开放”，不创建互动数据；当前页已有题时按钮置灰。
- 封面上的“题”和“互动”入口均不可操作。

### 题 Tab

- 题 Tab 始终显示计数 `1`，并包含 Figma 题 Tab 的头部信息、题目区、答案区、解析区和标签区视觉层级。
- 本轮可编辑字段只有题干文字、文本选项和正确答案；输入内容实时回显到画布题卡，画布题卡本身不可直接编辑。
- 默认创建 A-D 四个空文本选项，选项数量限制为 2–4；达到 4 项时禁用“添加选项”，达到 2 项时禁用删除选项。
- 每个选项使用“设为正确选项”按钮切换正确答案，允许同时选择多个，默认没有正确答案。
- “图片选项”、文字/图片/听力材料、题干语音、答案区、解析区、标签区和引用/保存操作保留只读或禁用的 Figma 视觉占位。

### 图层、删除与角色

- 题与其他页面元素一样出现在教研人员图层中，可选择、隐藏和恢复；隐藏只改变画布渲染，不移除元素、图层顺序或页码徽标。
- 题不加入播放顺序列表，也不加入音频列表、出现播放逻辑或 C 端互动数据。
- 题被选中时按 `Delete` 或 `Backspace` 始终打开二次确认。点击“取消”、按 `ESC`、点击遮罩或关闭弹窗均不删除；点击确认后移除题元素和对应图层顺序。
- 制作人员可以查看题卡、题 Tab 和题内容，但题干、选项、正确答案、图层和删除操作均为只读；切回教研人员后恢复编辑。

### 状态与操作

每个图片或动效需求在当前页面独立维护临时 UI 状态：

| 状态 | 画布表现 | 进入方式 | 离开方式 |
| --- | --- | --- | --- |
| 收起 | 仅显示“需求”按钮 | 展示态点击自身按钮 | 教研/制作点击按钮进入展示 |
| 编辑 | 显示富文本输入框和 Figma 风格工具栏，输入框获得焦点 | 教研单击展示态需求内容 | 输入框失焦进入展示；再次点击按钮立即收起 |
| 展示 | 显示富文本只读内容；空内容显示“未填写需求” | 编辑态失焦；新建或已有空需求默认进入 | 点击自身“需求”按钮收起；教研单击展示内容进入编辑 |

- 图片/动效置入后默认展开空需求展示态，但不自动激活输入框、不聚焦。
- 教研人员在收起态点击“需求”按钮先展开展示态；展示态单击需求内容区才进入编辑态并自动聚焦，编辑态点击按钮立即收起，已输入内容保留。
- 已填写需求和“未填写需求”均可通过展示内容进入编辑；制作人员端保持只读，不显示编辑器。
- 需求按钮固定在图片/动效框架左下角；展示态和编辑态的需求内容面位于按钮右侧，默认不超出框架边界。
- 内容面宽度随图片/动效框架的几何宽度同步伸缩，优先保持当前默认宽度；空间不足时在框架内收缩到可用最小宽度。
- 展示态在当前页面内常驻。点击其他图片、动效、其他画布元素或画布空白，不关闭已有展示态；同一页面允许多个展示态同时存在，但同一时间只保留一个编辑态。
- 切换页面或角色时清除当前页面的临时展开状态；切回后空需求仍按默认展示态显示，已填写需求默认收起，需求正文不丢失。
- 需求按钮不切换底部配置页签；画布元素选中和图片/动效置入也不改变当前底部页签。

### 角色差异

- `教研人员`：可编辑需求正文，支持富文本工具栏；需求正文由用户手动点击入口后编辑。
- `制作人员`：只能展开/收起并查看需求正文；不可编辑需求、不可看到富文本工具栏，但保留图片/动效移动和缩放能力。

## 2026-09-04 制作人员图片框直接上传

- 制作人员切换角色后，图片元素的内容区域变为可直接上传区域；点击图片内容或空图片框打开图片文件选择器。
- 图片需求区域继续阻止事件冒泡，点击“需求”按钮仍只负责展开或收起需求，不触发上传。
- 制作人员 Hover 或聚焦图片框时显示上传、删除操作；上传按钮打开图片选择器，删除按钮只清空图片产物并保留图片框、需求、位置和尺寸。
- 上传成功后图片在图片框内使用 `contain` 等比例完整展示；图片框仍支持移动和缩放，拖拽移动不会误触发上传。
- 未上传图片时需求默认展开；已有图片时需求默认收起；用户点击“需求”按钮后可再次切换。

### 焦点、层级与响应式

- 富文本工具栏属于需求编辑区域，点击工具栏按钮不触发失焦提交；焦点离开编辑区域后统一转展示态。
- 需求展示/编辑浮层位于元素内容区底部，按 Figma 的灰蓝卡片、22px 胶囊按钮、蓝色选中边框和富文本内容区呈现，并通过元素层级保证内容不被其他元素遮挡。
- 需求卡以画布级浮层承载，但仅提升需求卡本身的层级，不提升整张图片/动效；这样既能保证按钮和内容区可点击，也不遮挡其他元素的展示态。
- 编辑态的输入面板以独立内容面为边界，使用完整的蓝色描边和 10px 圆角；工具栏作为上方浮层，不参与输入面裁切，确保四角和四边在画布边缘、窄屏及元素重叠时完整可见。
- 教研展示态需求内容区提供可见焦点样式，支持 Enter / Space 进入编辑；制作人员展示内容不设置编辑焦点入口。
- 新增页面默认不创建文本元素，画布显示空白页状态；用户通过“文字”入口主动添加文本。
- 画布继续保持 16:9 比例；窄屏或元素较窄时需求内容面在框架内收缩，不改变元素几何比例。

## 2026-09-03 文本与领读语音补充需求优化

本轮依据 Figma 节点 `11816:68733`（领读语音需求弹窗）和 `12266:108109`（工作台页签）补充正文文本与领读语音交互；不改变封面文字、对话气泡字体层级或制作人员既有音频上传流程。

### 正文文本默认样式

- 正文 `TextElement` 默认渲染为 PingFang、16px、400、normal、24px（150%）。
- 文本浮动工具栏仍提供显式加粗、斜体、下划线、颜色和对齐操作；用户主动操作后保留对应显式样式。
- 封面文字和对话气泡不套用正文文本默认字体规则。

### 领读语音列表

- 仅列出当前页面的文本和对话元素，按 `page.elements` 写入顺序排列。
- 左侧显示总序号和类型编号；文本、对话分别独立递增，例如“文本1、对话1、文本2”。
- 台词文案以只读文本展示，不允许在列表内直接编辑；切换页面或角色后，列表根据同一份页面模型重新回显。
- 每项末尾显示“补”字按钮，按钮支持鼠标 Hover、键盘 Focus、明确的 `aria-label` 和 Tooltip。
- 台词文案承载区使用 `#D0DFE7`、10% 透明度（`rgba(208, 223, 231, 0.1)`）；列表项外层保持透明，不叠加背景色。

| 补充需求状态 | 按钮样式 | Tooltip |
| --- | --- | --- |
| 空或仅空白 | 灰色 | 暂无音频补充要求（如语气、音色等台词内容以外的要求） |
| 有内容 | 专业蓝 `#316CE3` | 显示 `voiceSupplement` 内容 |

### 补充需求弹窗

1. 教研人员点击某项“补”按钮，打开“领读语音需求”弹窗，并自动聚焦“补充”多行输入框。
2. 弹窗展示只读的“台词需求”，内容实时取当前文本/对话文案；该区域不可编辑。
3. 弹窗展示可编辑的“补充”多行纯文本输入框，用于填写语气、音色、语速等台词内容以外的需求。
4. 点击“确认”保存当前输入；输入为空或仅空白时保存为空，列表按钮恢复灰色状态。
5. 点击“取消”、右上角关闭按钮、遮罩，或按 `ESC` 均关闭弹窗且不保存本次编辑。
6. 弹窗打开期间，页面背景不可滚动；关闭后恢复原滚动状态。

## 2026-09-03 文本横向拖动与高度自适应

- 教研人员选中文本元素后，文本框左右中点显示横向缩放手柄；四角缩放手柄继续保留原有行为。
- 拖动左侧或右侧中点手柄时，仅沿水平方向调整文本框的位置和宽度；拖动过程中按新的宽度实时换行，并将文本框高度更新为内容所需高度。
- 文本框内容区域始终不显示滚动条；横向缩放完成后，文本、标注、字体样式、领读语音补充需求和音频配置保持不变。
- 横向拖动受画布边界和最小宽度限制；文本内容为空时仍保留可操作的最小高度。

## 页面结构

入口仍为 `/animation-book`，不新增路由。页面保持“顶部工作台信息 + 左侧页面缩略图 + 中央吸顶编辑工具栏/640×360 编辑画布 + 下方配置面板”的生产态布局，不预留审校区。顶部项目摘要调整为两行：第一行展示状态、项目编号、书名、课时备注和阅读等级，第二行展示职能、执行人和生产日期。

顶部工作台增加角色切换：

- `教研人员`：编辑内容结构与制作需求。
- `制作人员`：查看需求并上传产物。
- 默认进入教研人员，切换时保留当前页面、选中对象和本地编辑状态。

## 教研人员视图

- 页面缩略图区可新增、复制、删除和拖拽排序正文页面；封面固定在最上方。
- 画布工具可新增文本、图片占位、动效占位和对话气泡。
- 编辑画布工具与`网格系统`合并在中间编辑区顶部的整行吸顶工具栏；编辑区滚动时工具栏保持在顶部，缩放和网格开关位于工具栏右侧。
- 文本、页面结构、元素位置尺寸、图层顺序、出现顺序和播放顺序均可编辑。
- 默认选中正文文本的前一段文字，显示文本浮动工具栏；下方默认打开 `领读语音` 页签。
- 选中文字后，浮动工具栏显示 `+好词`、`+好句`、`+注释` 三个操作按钮。
- 点击标注按钮后，选中文字保持为原文范围并创建标注，画布退出编辑态，自动切换到对应的标注页签。
- `领读语音` 页签展示当前页面的文本语音和对话气泡语音；标注中的语音需求文案不作为语音列表项。
- `播放顺序`通过下方配置框右侧的独立 Tab 按钮打开播放顺序编辑器，不再跳转到旧的“出现 / 播放顺序”整块面板；按钮与其他页签保持相同激活和内容切换行为，但视觉上分开。
- 底部不再显示`页面内容`和`图层顺序`页签；选中任意画布元素时不自动进入或切换`页面内容`，`图层顺序`通过画布左下角悬浮入口打开，底层数据不删除。
- 每个需求槽位支持选择图片、动效或音频类型，填写标题，并使用轻量富文本编辑器输入需求。
- 富文本编辑器支持段落、粗体、斜体、有序/无序列表、链接、插入图片和图片说明。
- 视觉需求可绑定图片或动效元素；音频需求可绑定文本或气泡。
- 教研人员可以查看产物状态，但不提供图片、动效和音频产物上传入口。

### 文本标注

标注只在教研人员视图中提供。用户需要先进入文本编辑态并选中一段文字，三个标注按钮才可操作。

| 操作 | 结果 |
| --- | --- |
| 点击 `+好词` | 创建好词标注，使用橙色高亮，并打开好词页签 |
| 点击 `+好句` | 创建好句标注，使用波浪下划线，并打开好句页签 |
| 点击 `+注释` | 创建注释标注，使用虚线下划线，并打开注释页签 |
| 点击已有的好词 / 好句 / 注释标注块 | 底部切换到对应页签并激活该标注编辑项；重叠标注按创建顺序打开最早创建的一条，不进入文本编辑态 |
| 再次选择其他文字 | 保留已有标注，更新当前选择范围和浮动工具栏 |

同一文本支持多条标注；标注范围可以重叠。重叠时对应样式叠加，不能因为添加标注而改变文本块尺寸、网格或排版。

下方标注页签按当前类型展示标注列表。好词字段为注音模式、拼音、翻译、扩展讲解；好句字段为翻译、扩展讲解；注释字段为注释内容。三类标注都提供 `语音-需求` 和 `语音-补充` 文案，其中：

- 点击“快捷填入”会把当前标注原文写入 `语音-需求`。
- 这些字段仅用于制作需求，不生成音频源，不显示在 `领读语音` 列表，也不进入播放顺序。
- 标注没有配置内容时，点击删除立即移除；存在拼音、翻译、讲解、注释或语音文案时，先弹出确认弹窗。
- 在确认弹窗中点击取消，标注和原文均保留；确认删除只删除标注，不删除原文。

### 下方动态页签

- `领读语音`：聚合当前页面的文本和对话元素，按 `page.elements` 写入顺序展示总序号、类型编号和只读台词文案；每项通过“补”按钮维护领读语音补充需求。
- `好词`、`好句`、`注释`：仅在当前页面存在对应标注时出现，页签计数为该类型标注数量。
- `标准互动 1`：继续作为禁用占位，只表达互动后续入口位置；题元素通过独立的“题”Tab 编辑。
- `题`：当前页面存在题时显示，计数为 1；激活后展示题干、文本选项和正确答案配置。
- `播放顺序`：位于下方配置框右侧的独立 Tab 按钮；激活后只替换内容区，列表展示当前正文页的文本、图片、动效和对话，静态题不进入列表。

### 图层顺序悬浮工具

- 进入教研人员视图时，图层工具默认收起；画布左下角显示 32×32 图层按钮。
- 点击图层按钮展开深色半透明图层列表，再次点击按钮收起列表；浮层不改变画布尺寸和下方配置页签。
- 图层列表按 `zIndex` 从高到低展示，首行是最上层；每行包含拖拽手柄、元素类型图标、元素名称和显示/隐藏按钮。
- 当前支持文本、图片、动效、对话和题；题提供选择、隐藏/恢复与删除确认，互动保留类型图标/名称和下一阶段入口。
- 点击行选择对应画布元素；点击眼睛只切换显示状态，不触发行选择。
- 拖动手柄到目标行前/后调整图层顺序，拖拽过程中显示落点线；拖拽无效目标或拖回自身时不改变顺序。
- 图层行获得焦点后，方向键可上移/下移，Home 置顶，End 置底；排序只更新元素 `zIndex`。
- 隐藏元素从画布消失，但继续保留在列表中并可恢复；隐藏不改变出现顺序、播放顺序、展示方式和音频配置。
- 隐藏当前正在编辑的元素时，退出文本编辑和画布需求浮层，但保留图层行选中状态；恢复后不自动进入编辑态。

### 播放顺序入口

- 默认进入正文页时打开`领读语音`，右侧`播放顺序`按钮保持未激活。
- `播放顺序`按钮位于内容面板框架右侧，与其他页签分开；按钮使用 Tab 的激活态、焦点态和选中语义。
- 点击`播放顺序`按钮后，动态页签栏、`领读语音`、标注页签和禁用的`标准互动`页签均保留，仅将下方内容区切换为播放顺序编辑器。
- 点击其他动态页签后，播放顺序内容区关闭并返回对应页签；播放顺序按钮回到未激活态，已选标注和标注配置不丢失。
- 播放顺序只针对当前正文页，封面沿用当前空播放顺序状态。列表按序展示文本、图片、动效和对话元素，并显示序号、类型、内容/素材预览和`展示方式`；题为静态元素，不出现在列表中。
- 每行的`展示方式`独立配置，默认是`一直出现`，可切换为`播放时出现`；选择结果保存到对应元素，不影响其他行。
- 使用行内拖拽手柄调整顺序，拖拽经过目标行时显示落点线；同时提供上移/下移的键盘可操作入口。排序只移动元素，不改变其展示方式。
- 新增元素自动追加到列表并默认为`一直出现`；删除元素同步移除对应播放顺序项；页面切换后各页独立保留顺序和展示方式。
- 本期只保存并回显编辑配置，不接入 C 端播放、统一预览、时间轴或多轨执行。

## 制作人员视图

- 页面缩略图只允许选择，不显示新增、复制、删除和排序操作。
- 画布中的文字、页面结构、图层和顺序均为只读。
- “需求 / 产物”面板以只读方式渲染富文本需求和参考图片。
- 图片、动效需求槽位提供上传/替换产物；音频槽位提供上传/替换和播放。
- 图片和动效产物可在画布中移动、缩放；动效只显示静态占位或文件卡片，不播放。
- 对话气泡可移动、缩放和调整三角指向，但不可修改气泡文字、增删气泡或改变页面结构。
- 题卡和题 Tab 对制作人员只读展示；题干、选项和正确答案配置保留，但不能编辑，题卡仍不可拖动或缩放。

## 需求槽位

每个槽位展示：类型、标题、需求正文、目标对象、产物文件和状态。

状态包括：

- `待制作`：没有产物。
- `已上传`：已有有效产物。
- `上传失败`：本次上传失败，保留原有产物并允许重试。

视觉槽位没有目标元素时，制作人员仍可上传产物，但显示“待教研绑定画布位置”；音频上传只填充文本或气泡对应音频源，不改变播放顺序。标注语音字段不属于需求槽位的音频源。

## 关键异常与可访问性

- 文件类型不匹配时阻止写入并显示错误提示。
- 需求为空时显示警告，但不阻止继续编辑。
- 正文页再次添加题时不创建重复题；达到 2–4 个选项边界时禁用对应的增删入口。
- 题删除确认被取消、按 `ESC` 或由遮罩关闭时，题元素、图层和页码徽标均保留。
- 标注删除遵循“有配置先确认、无配置直接删除”；取消确认不改变标注和原文。
- 标注范围非法时不创建标注；文本被编辑后，超出新文本范围的标注自动移除，合法范围保留并更新原文。
- 播放顺序中拖拽到自身或无效目标时不改变顺序；顺序项引用已删除元素时不展示，并在下一次编辑时补齐当前页面缺失元素。
- 图层顺序中拖拽到自身或无效目标时不改变顺序；隐藏元素仍可排序和恢复，页面切换后各页面独立保留隐藏状态。
- 角色切换后不得丢失富文本、产物文件、音频和几何调整。
- 角色切换控件提供当前角色文本和明确的键盘焦点状态。
- 制作人员不可操作的控件使用隐藏或禁用态，同时在事件处理层拒绝对应写入。
- 图标按钮必须提供 `aria-label`，富文本编辑器工具栏按钮提供明确名称。

## 响应式与视觉

- 复用现有动画书工作区的中性色、品牌蓝、成功/警告/错误语义色。
- 需求槽位在窄屏下改为单列，画布保持 16:9 比例并允许工作区横向滚动。
- 中间编辑区吸顶工具栏和动态页签在窄屏下横向滚动，不压缩画布比例；网格开关仍属于吸顶工具栏，播放顺序独立按钮保持在内容面板右侧；图层浮层保持在画布左下方并支持展开、排序和显示切换；播放顺序行保持内容、展示方式和排序入口可用；标注字段保持可编辑。
- 本地文件读取期间保留原有有效产物；错误状态提供可重试入口。
- 题卡和页码按 16:9 画布比例缩放；窄屏下工作区允许横向滚动，不改变题的固定相对位置。
## 2026-09-04 封面交互补充

- 教研端在封面设置中切换左右/全屏布局；切换到全屏且存在文字时二次确认，确认后清空文字。
- 全屏媒体通过“图片/动效”下拉切换；切换前二次确认，切换后清空不兼容媒体及其需求。同为图片在布局间切换时沿用图片与图片需求。
- 封面画布元素均为固定模板，不响应移动、缩放、旋转、删除和图层调整；封面不提供图层顺序模块。
- 封面下方仅显示可收起/展开的“封面语音”模块。教研端编辑需求与补充需求，制作端上传音频；上传失败保留重试入口。
