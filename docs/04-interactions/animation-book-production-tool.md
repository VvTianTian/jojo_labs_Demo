# 动画书生产工具双角色协作交互说明

## 2026-09-14 移除制作需求/产物入口（当前生效）

- 图层列表行不再显示需求按钮或需求图标；画布图片/动效框不再显示需求胶囊、需求正文、展开/收起状态或产物状态入口。
- 正文下方不再提供“制作需求”或“需求 / 产物”Tab、面板、需求槽位、目标绑定和富文本编辑流程；生产人员不通过需求入口处理媒体。
- 生产人员在选择模式下直接操作选中的正文图片/动效框：上传、替换或删除媒体。图片接受图片文件，动效接受图片或视频文件；类型错误或本地读取失败时保留原媒体并提示重试。
- 封面继续使用固定媒体规则；封面语音是独立的音频上传/播放模块，不显示需求/补充表单。研究端可播放已有音频，生产端可上传或替换音频。
- `领读语音` 与文本标注中的语音需求/补充字段属于内容配置，和已移除的制作需求链路无关，本轮保留；文本、对话的 `audioUrl` 当前仍不提供上传入口。
- 本节覆盖下方历史交互中与制作需求、需求槽位、需求卡和需求面板冲突的描述；历史记录保留用于追溯，不代表当前界面。

## 2026-09-14 播放顺序分组排序

本轮在现有播放顺序平铺拖拽的基础上增加一层分组，不新增“普通排序 / 分组排序”模式开关。交互只修改当前正文页的 `playbackOrder`，不修改元素图层、出现顺序、几何、内容或其他页面状态。

### 信息结构

- 文本、动效、对话均可进入播放顺序并参与分组；图片和题保持静态，不进入列表。
- 目标播放项作为组头，被拖入项作为子项；组可以包含多个子项，但不允许组中组。
- 组头和每个子项都显示自己的“⼀直出现 / 播放时出现”下拉，分组不改变任何项原有展示方式，也不表达同时播放。
- 顶层项显示全局顺序号；组内项仅使用缩进和连接线与组头区分，不显示额外的组内序号，也不占用新的顶层序号。子项拖出后恢复顶层序号。

### 拖入分组

1. 拖动任意播放项左侧手柄；被拖项降低透明度，原位置保留占位。
2. 指针悬停顶层目标项时，目标行显示品牌蓝边框；进入目标内容区域时，显示“放入此项”或等价的内部落点提示。
3. 释放后目标项成为组头，被拖项插入该组子项末尾；已有子项不被覆盖，组头显示子项数量，子项缩进并显示连接线。
4. 释放后清除拖拽高亮和占位状态，顶层顺序号重新计算；组内顺序和各项展示方式保持可见且可继续编辑。

### 组内排序与拖出

- 在组内子项之间显示前/后落点线，可调整同组子项顺序。
- 将子项拖到顶层列表的前/后落点或列表间隙时，显示顶层落点线；释放后子项移出分组，成为独立顶层项。
- 将已有组头拖到顶层其他项前/后时，整个组（组头及子项）作为整体移动。
- 组内子项不允许再创建第二层嵌套；拖入已有子项内部时不产生写入，并显示不可用落点反馈。
- 拖到自身、无效目标或未进入有效落点时不改变数据。

### 删除、隐藏与新增

- 删除子项只移除该子项；删除带子项的组头时，子项按原组内顺序提升为顶层项。
- 隐藏元素保留在原有层级和播放顺序中，恢复后仍回到原位置；新增可播放元素默认追加到顶层。
- 分组操作只对教研人员开放；制作人员沿用播放顺序只读权限和现有角色边界。

### 键盘与可访问性

- 拖拽手柄提供明确的 `aria-label`；播放顺序容器和组容器使用可读的层级语义。
- 聚焦拖拽手柄后，方向键调整当前层级内顺序；`ArrowRight` 将项放入前一个可用顶层项，`ArrowLeft` 将子项移出到顶层；`Home/End` 移动到当前层级首/尾。
- 键盘排序后同步更新序号和组内标识；焦点保留在被移动项，`Escape` 取消当前拖拽状态。

## 2026-09-14 编辑面 Tab 区与播放顺序按钮

### Tab 区结构

- 本规则只调整正文编辑区下方的内容配置头部，不改变左侧页面缩略图、中央画布、顶部工具栏或页面/元素业务数据。
- `领读语音`、`好词`、`注释`采用同一组横向页签 Tab；页签根据当前页面已有内容显示数量标记，激活态使用统一的文字颜色和白色卡片表面，并与下方内容面板相接。既有 `好句`、`题` 等扩展页签继续按当前页面状态显示，不因本轮调整删除已有能力。
- 内容 Tab 视觉参考 [Ant Design Tabs 卡片式 `card` 类型](https://5x.ant.design/components/tabs-cn)：Tab 使用独立浅色/白色卡片表面、顶部圆角和统一内边距，激活 Tab 与下方白色内容面板相接；不引入可关闭的 `editable-card` 能力。
- `播放顺序`位于 Tab 区最右侧，以独立按钮呈现，与内容 Tab 保持视觉间隔，不作为内容 Tab 连续项参与布局。

### 播放顺序切换

- 点击未激活的`播放顺序`按钮后，保留 Tab 区和按钮，只替换下方内容区域为播放顺序编辑面板；内容 Tab 均呈未选中态。
- 播放顺序激活期间，当前页面、画布、选中元素、角色、文本/标注编辑内容和其他业务状态均不重置。
- 再次点击已激活的`播放顺序`按钮后，关闭播放顺序内容面板，并默认激活`领读语音`Tab；当前页面、画布、选中元素和顺序数据保持不变。
- 点击`领读语音`、`好词`、`好句`或`注释`等内容 Tab 后，关闭播放顺序内容面板并激活对应页签；不跳转页面或清空内容。
- 内容 Tab 使用 `role="tab"` 和 `aria-selected` 表达激活态；`播放顺序`使用独立按钮语义和 `aria-pressed` 表达当前是否打开。

## 2026-09-11 正文元素右键菜单

### 入口与覆盖范围

- 仅正文页、选择模式下的画布元素响应右键菜单，覆盖文字、图片、动效、对话、题和互动六类元素；封面沿用固定模板，不提供该入口。
- 右键目标会先自动成为当前选中元素，再以鼠标视口坐标打开菜单。重叠时由可见的上层元素命中；隐藏元素不在画布命中范围内，仍可从图层列表选择并恢复。
- 文本编辑态、输入框/文本域操作和画布移动模式不拦截原有编辑或原生右键行为。

### 菜单项目与写入规则

- 菜单固定展示“置于顶层、上移一层、下移一层、置于底层、隐藏/显示、删除”。图层操作只重排当前正文页元素的 `zIndex`，顶层/底层边界不跨页写入。
- “隐藏”只将当前元素从画布渲染中移除，元素、出现顺序、播放顺序、展示方式和音频配置均保留；隐藏元素再次打开菜单或从图层列表操作时，文案为“显示”，恢复后回到画布。
- “删除”复用现有二次确认和关联数据清理。确认前、取消、关闭按钮、遮罩点击或 `Escape` 均不删除；确认后才移除元素及其关联页签和顺序数据。
- 教研人员可使用全部六项；制作人员可使用图层调整和隐藏/显示，删除项显示禁用态，鼠标点击、Enter/Space、快捷键和事件处理层均拒绝删除。该例外只作用于右键菜单，现有图层浮层权限保持不变。

### 打开、定位、键盘与关闭

- 菜单使用固定视口定位，不随画布缩放放大；靠近右侧或底部窗口边缘时自动向内调整，窄屏下仍保持完整可见和可聚焦。
- 菜单容器使用 `role="menu"`，项目使用 `role="menuitem"`；画布元素获得焦点后可用 `Shift+F10` 或 Context Menu 键打开。菜单内支持方向键循环移动、Home/End 跳转、Enter/Space 执行和 `Escape` 关闭并回到触发元素焦点。
- 点击菜单外部、`Escape`、切换正文页或角色时关闭菜单；菜单操作完成后关闭，删除确认弹窗单独接管焦点和关闭行为。

## 2026-09-10 画布四档缩放与移动工具

### 工具栏与缩放下拉

- 封面和正文使用同一套画布视图工具栏。研究端工具顺序为“选择 → 移动 → 文字 → 图片 → 动效 → 对话 → 题 → 互动”，制作端隐藏编辑工具，仅保留“选择 → 移动”、缩放下拉和网格系统；正文图片/动效框直接提供媒体操作。
- “选择”和“移动”为互斥工具按钮，按钮使用 `aria-pressed` 表示当前模式；选择按钮使用指针图标，移动按钮使用手掌图标。移动模式画布显示 `grab`，拖拽中显示 `grabbing`，按钮和画布均提供可见焦点态。
- 缩放控件使用可键盘操作的下拉菜单，选项固定为“当前尺寸 640×360”、“800×450”、“放大 960×540”和“1200×675”，默认选择当前尺寸。首期不支持滚轮、自由百分比、触控缩放或自动适配。

### 顶部工具操作说明

| 工具 | 操作说明 | 边界与状态 |
| --- | --- | --- |
| 选择 | 切换为元素选择模式。点击画布元素可选中对象，并恢复该元素已有的移动、缩放、文本编辑或媒体上传等交互。点击画布空白区域取消选择。 | 与“移动”互斥；选中态通过高亮边界和编辑手柄表达。 |
| 移动 | 切换为画布视口平移模式。按住鼠标左键拖动画布，视口随指针移动；画布元素、题卡、互动卡和媒体框在此模式下仅作为平移触发区域。 | 不触发元素选中、点击、文本编辑、元素移动、元素缩放、上传或需求编辑，不修改元素坐标、尺寸、选中状态或其他业务数据。拖拽时显示 `grabbing`，未拖拽时显示 `grab`；支持方向键平移，`Escape` 返回选择模式。 |
| 文字 | 在当前正文页新增文本框，创建后自动选中并进入文本编辑状态。 | 仅教研端正文页显示；制作端隐藏。 |
| 图片 | 在当前正文页新增图片框和占位，创建后自动选中；制作端在选中的图片框中直接上传、替换或删除图片。 | 仅教研端显示新增入口；不创建需求槽位或需求状态。 |
| 动效 | 在当前正文页新增独立动效框和占位，创建后自动选中；每次点击都创建新的独立动效元素，制作端可在选中的动效框中直接上传、替换或删除媒体。 | 仅教研端显示新增入口；不覆盖已有动效，不实现动效播放。 |
| 对话 | 在当前正文页新增对话气泡并自动选中；双击气泡进入文字编辑，失焦后退出编辑。 | 仅教研端显示新增入口；新气泡默认不自动聚焦输入框。 |
| 题 | 在当前正文页添加标准选择题并打开“题”Tab；已有题时改为选中并查看/编辑现有题目。 | 每页最多一个题；已有互动时禁用，不在封面显示。制作端可查看但不可修改。 |
| 互动 | 在当前正文页添加投票互动并打开“题”Tab；已有互动时改为选中并查看/编辑现有互动。 | 与题互斥；已有题时禁用，不在封面显示。制作端可查看但不可修改。 |

### 视图缩放规则

- 缩放只改变画布物理显示尺寸和内部视觉比例；元素仍使用 1920×1080 逻辑坐标，缩放前后不改写元素 `x/y/width/height`、资源、图层或播放顺序。
- 文字、对话、题和投票互动的内容、字号/行高、留白、气泡三角、题卡和互动卡内部视觉内容整体按视图比例缩放；图片和动效的画布框及资源显示区域按视图比例缩放。
- 图片/动效标签、占位图、上传/删除入口、选择边框与手柄、图层按钮、页码和其他编辑辅助 UI 使用固定编辑像素，不因放大档位变大。
- 封面左右布局、全屏布局和正文空白页均保留原有几何、媒体类型和角色权限，仅改变视图显示比例。网格覆盖层随画布同步覆盖，不改变业务数据。

### 移动画布与居中

- 选择模式下沿用既有选择、文本编辑、元素移动/缩放和媒体上传交互。
- 移动模式下从画布任意空白区、元素内容区、题卡、互动卡或媒体框拖拽均只改变画布视口滚动位置；不改变选中对象、元素坐标、尺寸、文本内容或编辑态，也不触发元素点击或媒体上传动作。
- 视口平移受横向/纵向滚动边界限制；窄屏或放大画布超出窗口时保持 16:9，并可通过视口滚动条或移动工具访问完整内容。
- 切换页面或缩放档位后，视口在下一帧重新居中；角色切换回选择模式，不保留正在进行的拖拽。
- `Escape` 在移动模式下回到选择模式；移动按钮、缩放下拉、网格开关和画布视口支持键盘焦点和屏幕阅读器名称。动画过渡遵守 `prefers-reduced-motion`。

### 角色范围与验收

- 教研端可使用全部编辑工具和视图工具；制作端只隐藏编辑工具，保留选择、移动、缩放和网格，并在正文图片/动效框中直接操作媒体。两端都可在封面和正文使用四档视图。
- 验收覆盖空封面、正文空页、含文字/图片/动效/对话/题/互动页面，以及切页、切换档位、窄屏溢出和移动边界。
- 移动模式拖拽前后对比业务模型和选中状态应无变化；选择模式下既有文本编辑、元素移动/缩放、图层、播放顺序、媒体上传和角色权限流程不得回归。

## 2026-09-09 正文多动效与媒体框背景透明度

本轮变更仅作用于正文页；本文所说“每页”均指正文页，不包含封面。封面既有媒体规则保持不变：左右布局使用固定图片，全屏布局使用固定单媒体模块，本轮不改变封面媒体数量、媒体类型切换或固定位置规则。透明度规则也不适用于封面。

### 动效新增、选择与编辑

- 教研人员点击“添加动效”时，每次都在当前正文页创建一个新的、独立的动效元素；入口可重复操作，不因当前页已有动效而改为打开、覆盖或复用已有动效。已有动效的媒体、几何和顺序均保留。
- 同一正文页可以有多个动效。多个动效允许重叠；每个动效都可独立选择、移动、缩放、上传/替换/删除媒体、隐藏/恢复和删除。重叠点击命中可见的上层元素，底层动效可通过图层列表选择；选择不会临时改变图层顺序。
- 每个动效只保存自身媒体、几何、图层和播放顺序数据；新增动效不清空、不合并也不覆盖已有动效。新动效沿用既有动效框的初始位置、尺寸及移动/缩放约束，并在创建后保持选中。

### 图片/动效框背景

- 仅正文画布中的图片框和动效框，其背景层使用 50% 透明度（不透明度为 50%），用于重叠时区分各框边界。
- 已上传图片或动效媒体本身保持原有不透明度；50% 透明度不作用于资源内容、类型标签、其他标签或任何文字。重叠时仅降低框的背景层，不降低资源和内容层的可读性。
- 图片/动效及其媒体操作仍作为同一元素渲染，共享所属元素的图层顺序；背景层透明度不创建额外置顶层。

### 角色、顺序与状态

- `教研人员`：可重复添加动效，并对每个动效独立进行选择、移动、缩放、图层排序、隐藏/恢复和删除；教研端不显示正文媒体上传入口。
- `制作人员`：不可添加或删除动效框或修改播放顺序；正常图层浮层不提供排序入口，本轮可通过正文元素右键菜单调整图层和隐藏/显示；可选择已有图片/动效框并移动、缩放，以及直接上传、替换或删除对应媒体。删除媒体不删除元素、位置、尺寸或顺序。
- 空正文页继续不预置元素或顺序项；画布显示既有空白页状态，“添加动效”入口可用，播放顺序和图层列表不显示动效项。首次添加后出现一个独立动效框、图层项和播放顺序项；继续添加只增加新的独立项，已有项状态不变。
- 动效参与当前正文页的播放顺序。每个动效各有一条顺序项，新增时追加并默认使用“一直出现”；每条动效的“展示方式”可独立配置和排序。播放顺序排序不改变图层顺序，图层排序也不改变播放顺序；图片仍不参与播放顺序。

### 窄屏与可访问性

- 窄屏下画布继续保持 16:9，并允许工作区横向滚动；多个动效不被自动合并或改为单列，既有重叠关系、几何比例和 50% 背景透明度保持不变。工具栏、动态页签、播放顺序行和图层入口继续可横向访问，不出现额外需求面板。

- 三角控制点保留 `role=slider` 语义：右/下方向键顺时针增加 1°，左/上方向键减少 1°，Shift+方向键按 15° 调整，Home 设置 `0°`，End 设置 `359°`；属性面板可输入角度进行精细调整。
- 旧数据中的 `direction`、`tailX`、`tailY` 只在加载时转换为 `tailAngle`，转换后不再驱动交互。

- 正文页点击“互动”新增一个投票模块，自动选中并打开“题 1”页签，页码旁立即显示与题一致的“题”徽标。重复点击打开已有互动；题与互动互斥，封面不提供添加。

- 教研端可编辑，制作端只读查看互动内容；切换角色和页面保留会话状态。保存确认当前配置，取消恢复本轮编辑前内容，均不表示服务端持久化。
- 互动固定位置且不显示缩放手柄；图层中可选择、隐藏/恢复。隐藏保留页码徽标，删除须二次确认；确认删除后清理关联配置、页签和徽标，释放题入口。
- 本轮只实现生产态配置与静态卡片，不提交投票、不生成统计结果。“标准互动”历史占位不作为新互动入口。
