# 动画书生产工具双角色协作交互说明

## 页面结构

入口仍为 `/animation-book`，不新增路由。页面保持“顶部工作台信息 + 左侧页面缩略图 + 中央 640×360 编辑画布 + 下方配置面板”的生产态布局，不预留审校区。

顶部工作台增加角色切换：

- `教研人员`：编辑内容结构与制作需求。
- `制作人员`：查看需求并上传产物。
- 默认进入教研人员，切换时保留当前页面、选中对象和本地编辑状态。

## 教研人员视图

- 页面缩略图区可新增、复制、删除和拖拽排序正文页面；封面固定在最上方。
- 画布工具可新增文本、图片占位、动效占位和对话气泡。
- 文本、页面结构、元素位置尺寸、图层顺序、出现顺序和播放顺序均可编辑。
- “需求 / 产物”面板展示当前页面的产物需求槽位。
- 每个需求槽位支持选择图片、动效或音频类型，填写标题，并使用轻量富文本编辑器输入需求。
- 富文本编辑器支持段落、粗体、斜体、有序/无序列表、链接、插入图片和图片说明。
- 视觉需求可绑定图片或动效元素；音频需求可绑定文本、气泡或页面领读语音。
- 教研人员可以查看产物状态，但不提供图片、动效和音频产物上传入口。

## 制作人员视图

- 页面缩略图只允许选择，不显示新增、复制、删除和排序操作。
- 画布中的文字、页面结构、图层和顺序均为只读。
- “需求 / 产物”面板以只读方式渲染富文本需求和参考图片。
- 图片、动效需求槽位提供上传/替换产物；音频槽位提供上传/替换和播放。
- 图片和动效产物可在画布中移动、缩放；动效只显示静态占位或文件卡片，不播放。
- 对话气泡可移动、缩放和调整三角指向，但不可修改气泡文字、增删气泡或改变页面结构。

## 需求槽位

每个槽位展示：类型、标题、需求正文、目标对象、产物文件和状态。

状态包括：

- `待制作`：没有产物。
- `已上传`：已有有效产物。
- `上传失败`：本次上传失败，保留原有产物并允许重试。

视觉槽位没有目标元素时，制作人员仍可上传产物，但显示“待教研绑定画布位置”；音频上传只填充对应音频源，不改变播放顺序。

## 关键异常与可访问性

- 文件类型不匹配时阻止写入并显示错误提示。
- 需求为空时显示警告，但不阻止继续编辑。
- 角色切换后不得丢失富文本、产物文件、音频和几何调整。
- 角色切换控件提供当前角色文本和明确的键盘焦点状态。
- 制作人员不可操作的控件使用隐藏或禁用态，同时在事件处理层拒绝对应写入。
- 图标按钮必须提供 `aria-label`，富文本编辑器工具栏按钮提供明确名称。

## 响应式与视觉

- 复用现有动画书工作区的中性色、品牌蓝、成功/警告/错误语义色。
- 需求槽位在窄屏下改为单列，画布保持 16:9 比例并允许工作区横向滚动。
- 本地文件读取期间保留原有有效产物；错误状态提供可重试入口。
