## 2026-09-03 编辑工具栏与播放顺序入口调整

本轮根据最新设计稿调整中间编辑区的工具栏布局和播放顺序入口位置；既有播放顺序数据和编辑行为保持不变。

## 页面结构

入口仍为 `/animation-book`，不新增路由。页面保持“顶部工作台信息 + 左侧页面缩略图 + 中央吸顶编辑工具栏/640×360 编辑画布 + 下方配置面板”的生产态布局，不预留审校区。顶部项目摘要调整为两行：第一行展示状态、项目编号、书名、课时备注和阅读等级，第二行展示职能、执行人和生产日期。

顶部工作台增加角色切换：

- `教研人员`：编辑内容结构与制作需求。
- `制作人员`：查看需求并上传产物。
- 默认进入教研人员，切换时保留当前页面、选中对象和本地编辑状态。

## 教研人员视图

- 页面缩略图区可新增、复制、删除和拖拽排序正文页面；封面固定在最上方。
- 画布工具可新增文本、图片占位、动效占位和对话气泡。
- 编辑画布工具与`网格系统`合并在中间编辑区顶部的整行吸顶工具栏；编辑区滚动时工具栏保持在顶部，缩放和网格开关位于工具栏右侧。
- 文本、页面结构、元素位置尺寸、图层顺序、出现顺序和播放顺序均可编辑。
- 默认选中正文文本的前一段文字，显示文本浮动工具栏；下方默认打开 `领读语音` 页签。
- 选中文字后，浮动工具栏显示 `+好词`、`+好句`、`+注释` 三个操作按钮。
- 点击标注按钮后，选中文字保持为原文范围并创建标注，画布退出编辑态，自动切换到对应的标注页签。
- `领读语音` 页签展示当前页面的文本语音和对话气泡语音；标注中的语音需求文案不作为语音列表项。
- `播放顺序`通过下方配置框右侧的独立 Tab 按钮打开播放顺序编辑器，不再跳转到旧的“出现 / 播放顺序”整块面板；按钮与其他页签保持相同激活和内容切换行为，但视觉上分开。
- 底部不再显示`页面内容`和`图层顺序`页签；页面内容的既有自动进入行为保留，`图层顺序`继续通过画布图层入口打开，底层数据不删除。
- 每个需求槽位支持选择图片、动效或音频类型，填写标题，并使用轻量富文本编辑器输入需求。
- 富文本编辑器支持段落、粗体、斜体、有序/无序列表、链接、插入图片和图片说明。
- 视觉需求可绑定图片或动效元素；音频需求可绑定文本或气泡。
- 教研人员可以查看产物状态，但不提供图片、动效和音频产物上传入口。

### 文本标注

标注只在教研人员视图中提供。用户需要先进入文本编辑态并选中一段文字，三个标注按钮才可操作。

| 操作 | 结果 |
| --- | --- |
| 点击 `+好词` | 创建好词标注，使用橙色高亮，并打开好词页签 |
| 点击 `+好句` | 创建好句标注，使用波浪下划线，并打开好句页签 |
| 点击 `+注释` | 创建注释标注，使用虚线下划线，并打开注释页签 |
| 再次选择其他文字 | 保留已有标注，更新当前选择范围和浮动工具栏 |

同一文本支持多条标注；标注范围可以重叠。重叠时对应样式叠加，不能因为添加标注而改变文本块尺寸、网格或排版。

下方标注页签按当前类型展示标注列表。好词字段为注音模式、拼音、翻译、扩展讲解；好句字段为翻译、扩展讲解；注释字段为注释内容。三类标注都提供 `语音-需求` 和 `语音-补充` 文案，其中：

- 点击“快捷填入”会把当前标注原文写入 `语音-需求`。
- 这些字段仅用于制作需求，不生成音频源，不显示在 `领读语音` 列表，也不进入播放顺序。
- 标注没有配置内容时，点击删除立即移除；存在拼音、翻译、讲解、注释或语音文案时，先弹出确认弹窗。
- 在确认弹窗中点击取消，标注和原文均保留；确认删除只删除标注，不删除原文。

### 下方动态页签

- `领读语音`：聚合当前页面的文本元素和对话气泡语音，展示文本/对话类型、内容和需求/已上传状态。
- `好词`、`好句`、`注释`：仅在当前页面存在对应标注时出现，页签计数为该类型标注数量。
- `标准互动 1`：禁用占位，只表达后续入口位置；不可点击、不可编辑、不可产生题目、选项、反馈或跳转数据。
- `播放顺序`：位于下方配置框右侧的独立 Tab 按钮；激活后只替换内容区，列表展示当前正文页的全部元素。

### 播放顺序入口

- 默认进入正文页时打开`领读语音`，右侧`播放顺序`按钮保持未激活。
- `播放顺序`按钮位于内容面板框架右侧，与其他页签分开；按钮使用 Tab 的激活态、焦点态和选中语义。
- 点击`播放顺序`按钮后，动态页签栏、`领读语音`、标注页签和禁用的`标准互动`页签均保留，仅将下方内容区切换为播放顺序编辑器。
- 点击其他动态页签后，播放顺序内容区关闭并返回对应页签；播放顺序按钮回到未激活态，已选标注和标注配置不丢失。
- 播放顺序只针对当前正文页，封面沿用当前空播放顺序状态。列表按序展示文本、图片、动效和对话元素，并显示序号、类型、内容/素材预览和`展示方式`。
- 每行的`展示方式`独立配置，默认是`一直出现`，可切换为`播放时出现`；选择结果保存到对应元素，不影响其他行。
- 使用行内拖拽手柄调整顺序，拖拽经过目标行时显示落点线；同时提供上移/下移的键盘可操作入口。排序只移动元素，不改变其展示方式。
- 新增元素自动追加到列表并默认为`一直出现`；删除元素同步移除对应播放顺序项；页面切换后各页独立保留顺序和展示方式。
- 本期只保存并回显编辑配置，不接入 C 端播放、统一预览、时间轴或多轨执行。

## 制作人员视图

- 页面缩略图只允许选择，不显示新增、复制、删除和排序操作。
- 画布中的文字、页面结构、图层和顺序均为只读。
- “需求 / 产物”面板以只读方式渲染富文本需求和参考图片。
- 图片、动效需求槽位提供上传/替换产物；音频槽位提供上传/替换和播放。
- 图片和动效产物可在画布中移动、缩放；动效只显示静态占位或文件卡片，不播放。
- 对话气泡可移动、缩放和调整三角指向，但不可修改气泡文字、增删气泡或改变页面结构。

## 需求槽位

每个槽位展示：类型、标题、需求正文、目标对象、产物文件和状态。

状态包括：

- `待制作`：没有产物。
- `已上传`：已有有效产物。
- `上传失败`：本次上传失败，保留原有产物并允许重试。

视觉槽位没有目标元素时，制作人员仍可上传产物，但显示“待教研绑定画布位置”；音频上传只填充文本或气泡对应音频源，不改变播放顺序。标注语音字段不属于需求槽位的音频源。

## 关键异常与可访问性

- 文件类型不匹配时阻止写入并显示错误提示。
- 需求为空时显示警告，但不阻止继续编辑。
- 标注删除遵循“有配置先确认、无配置直接删除”；取消确认不改变标注和原文。
- 标注范围非法时不创建标注；文本被编辑后，超出新文本范围的标注自动移除，合法范围保留并更新原文。
- 播放顺序中拖拽到自身或无效目标时不改变顺序；顺序项引用已删除元素时不展示，并在下一次编辑时补齐当前页面缺失元素。
- 角色切换后不得丢失富文本、产物文件、音频和几何调整。
- 角色切换控件提供当前角色文本和明确的键盘焦点状态。
- 制作人员不可操作的控件使用隐藏或禁用态，同时在事件处理层拒绝对应写入。
- 图标按钮必须提供 `aria-label`，富文本编辑器工具栏按钮提供明确名称。

## 响应式与视觉

- 复用现有动画书工作区的中性色、品牌蓝、成功/警告/错误语义色。
- 需求槽位在窄屏下改为单列，画布保持 16:9 比例并允许工作区横向滚动。
- 中间编辑区吸顶工具栏和动态页签在窄屏下横向滚动，不压缩画布比例；网格开关仍属于吸顶工具栏，播放顺序独立按钮保持在内容面板右侧；播放顺序行保持内容、展示方式和排序入口可用；标注字段保持可编辑。
- 本地文件读取期间保留原有有效产物；错误状态提供可重试入口。
