# Radius

Status: Draft

## Purpose

定义控件、卡片和容器的圆角等级，保持专业克制的 B 端视觉气质。

## Radius Scale

- `4px`: 细小标签、紧凑状态块
- `6px`: 输入框、轻量控件的默认圆角
- `8px`: 卡片和区块容器的基础圆角
- `10px`: Button 专用基线圆角，当前 Primary 默认使用这一档
- `12px`: Modal、重点卡片和强调型容器
- `999px`: 胶囊按钮、状态 Pill、圆形控件

## Token Sources

- `radius`
- `border-width`

## Usage Notes

- 不通过过大圆角制造“活泼感”，优先保持专业、稳定、可扫描的 B 端观感。
- Button 允许比输入框更圆一些，但仍要控制在 `10px` 左右，避免与页面容器圆角脱节。
- 同一操作组中的按钮圆角必须一致，不在主次按钮之间混用不同几何语言。
- 高密度场景优先使用 `6px` 或 `10px`，避免 `12px+` 在工具栏和表格中显得过软。
